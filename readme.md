# MUD 游戏 - 更新日志

## 2026-08-28 · 真意、自创武学、自制装备与前端一致性修复

- **真意触发判定** — 补全绝招目标与实际伤害记录，依赖命中的真意只在绝招确实命中时生效；北冥恢复类等非攻击效果仍按成功施展判定，魅惑等满足条件必中的绝招保留原有机制。
- **真意阈值与试炼事务** — 无极绝境改为按本次受击后的预计气血判断，跨过低血阈值即可触发；试炼建房、扣精力、传送和化身初始化任一步失败都会清理现场并退还精力，避免角色或资源卡死。
- **悟痕发放收敛** — 悟痕只通过背包对象接口发放，去除失败后遗留游离对象的旧分支；绝招能量快照会原样恢复临时字段及有效期。
- **自创武学服务端校验** — 创建、追加和替换 PFM 统一校验来源技能、3000级要求、对应部位、重复项、每部位上限及整本最多一个门派 PFM；内功首词条强制为内力化血，所有材料均先成功扣除再写入数据。
- **自创武学旧档与品质修复** — 品质按单一部位的最大词条数计算且最高为6；修复重复词条等级丢失、嵌套 PFM 浅拷贝串数据、短技能 ID 碰撞和多本秘籍误恢复同一技能，并拒绝恢复明确属于其他玩家的自创技能。
- **自创战斗效果修复** — 不屈按致命攻击后的预计气血触发并正确提供短暂无敌；溅射只读取本次攻击实际使用的部位，单目标追加攻击原目标，多目标随机追加攻击一个敌人；战神描述移除未实装的吸收效果。
- **自制装备事务修复** — 升级、洗词条和新增词条改为材料扣除成功后才修改装备；替换词条保留原词条的能力标记与数组位置，失败时回退新词条石；最高重铸档统一按50次计算。
- **自制装备名称与入口** — 重铸改名统一限制为2至5个汉字并执行敏感词检查；物品详情的重铸入口只对明确的自制装备开放，不再把带词条的普通装备误判为自制装备。
- **前端健壮性** — 服务端数据解析改用 JSON/JSON5，不再动态执行文本；自创武学面板补齐空数据、非法步骤、词条上限和必选内力化血保护，并移除面向开发者的技能 ID、品质编号展示；底部确认框适配手机安全区。
- **自动回归** — 新增前端、真意、自创武学和自制装备关键规则校验，并纳入 `npm run validate:systems`。

## 2026-08-27 · 真意战斗与试炼生命周期修复

- **绝招绑定与失败清理** — 真意伤害、忽视防御和附加效果只在对应绑定绝招的实际释放期间生效；绝招返回失败或抛错也会立即清理上下文，不再强化后续普通攻击。
- **命中叠层修正** — 飞龙掌力与雷贯改为造成实际伤害后叠层，闪避、招架或零伤害不再增加层数；新层数从后续攻击开始生效。
- **附伤遵守防御** — 生死符附伤、紫电雷伤和金顶反震不再使用百分百忽视防御，统一按目标正常防御结算，面板同步写明结算方式。
- **试炼热更新续接** — 地图脚本更新时恢复真意副本隔离、动作栏和武意化身，并沿用原试炼截止时间；旧化身计时器会停止，避免更新后误判失败。
- **离场与叛师保护** — 试炼状态只在成功移动离场后清理，公共禁地返回失败时会尝试回到住宅并允许再次确认；真意试炼未离场时禁止使用叛师符。
- **成功次数与奖励事务** — 手动挑战只有成功完成才计入每日次数，失败尝试不计次；扫荡奖励必须完整加入背包后才扣除精力和次数，任一道具发放失败会整体回滚。
- **状态与整数规则** — 绝招连携记录在战斗结束时清理，有明确持续秒数的冷却继续保留以防换战斗重置；全部正数效果统一向上取整为整数。
- **生产前端清理** — 构建前自动删除旧的哈希 JS/CSS bundle，只保留当前生产版本；真意校验现包含独立副本运行测试，地图房间统计修正为 333 个。

## 2026-08-25 · 前端体验稳定性修复

- **断线重连保护** — 增加连接代次校验，旧 WebSocket 回调和旧页面定时器不再覆盖新连接；连接失败不会在无提示的情况下延迟刷新页面。
- **重连缓存清理** — 切换角色或重新登录时清理属性、真意、排行、商店和仓库的会话数据，避免显示上一名角色的数据。
- **移动端面板布局** — 修复窄屏下属性、称号、真意面板和底部操作栏被裁切的问题，底栏支持自动换行。
- **仓库/商店数据健壮性** — 增加增量数据排队和数组校验，避免基础快照延迟时物品数量不同步或面板报错。
- **确认框与消息队列** — 修复购买数量异常、确认回调抛错后窗口残留、消息分页多一条及切换房间后滚动状态残留。
- **点击事件生命周期** — 游戏主界面事件改为命名空间绑定，嵌套按钮点击可正确解析命令，重复挂载不再触发多次操作。

## 2026-08-23 — 门派真意系统重构与界面整合

- **真意面板回归游戏原生风格** — 面板改为与技能列表一致的紧凑行式布局；真意名称本身随内部品质档位改变颜色，名称行只显示启用状态和当前重数，展开详情不再重复显示重数、品质或开发字段。
- **效果描述改为精确当前值** — 八门派共 40 项真意均由实际战斗公式按当前重数动态生成描述，完整覆盖第一重至第十重；移除模糊估算、数值区间和面向开发的技能分类措辞，伤害增益统一表述为下一次或当前技能伤害提高。
- **品质参与实际成长** — 真意重数在内部映射至与技能、人物境界一致的颜色档位，档位系数参与全部可成长数值计算，不再只是视觉换色；内部品质编号不会在游戏界面或升级消息中展示。
- **悟痕改为真实道具** — 各真意悟痕改为不可交易、不可丢弃、可堆叠的背包道具；旧版角色计分字段会自动迁移为对应悟痕道具，判师时同时清理原门派悟痕和真意数据。
- **升级改为主消息二次确认** — 真意面板不再常驻显示玄晶数量、悟痕数量或下一重消耗；点击升级后，主消息页才会列出当前效果、升级后精确效果、资源消耗与持有数量，并提供“确认升级/取消”操作，确认时会再次校验状态和道具。
- **纯机制真意单独处理** — 少林「金刚不坏」为唯一纯机制真意：每 600 秒最多抵挡一次致命伤害并保留 1 点气血；该效果没有成长数值，因此无需且不能升级。
- **试炼入口与实例修正** — 挑战、扫荡一次和扫荡十次仅保留在禁地试炼 NPC，不再出现在真意面板；门派禁地使用公共实例，战斗试炼使用玩家独立实例，完成或失败后返回公共禁地，避免玩家互相串场。
- **解锁与旧角色迁移加固** — 武帝且通过武道塔 100 层的旧角色会在登录或打开属性面板时补发本门禁地权限；跨门派移动、直传和旧房间入口继续执行门派校验，异门残留数据自动清理。
- **战斗与平衡校正** — 内部继续双重排除最高品质技能；仅明确绑定的真意获得伤害、破防、控制、减伤或资源效果，移除意外的通用技能增伤，并修正罗汉阵人数计算及数项描述与实装不一致的问题。
- **品质成长与整数数值重算** — 品质档位改为真意的主要强度层级，跨档成长显著提高；重数只承担同档内的小幅成长，40 项效果的面板值与实际结算值统一取整，不再出现小数或显示值、实装值分叉。
- **忽视防御单位修正** — 依据底层伤害公式确认忽视防御为百分比属性；所有相关真意统一改为准确百分比说明和百分比加算，移除“点破防”等错误单位。
- **旧试炼残留自动修复** — 玩家再次打开真意系统或开始挑战时，会核验独立试炼房间与武意化身是否仍存在；更新前遗留的“试炼尚未结束”状态会自动清理并允许重新挑战。
- **禁地 NPC 与试炼难度重整** — 八处禁地只保留五名正式试炼引导 NPC，无关旧敌人不再生成；旧 NPC 数值作为正确基准保留，新试炼化身取消玩家气血 5～8 倍等动态放大，改为 1200 万～3000 万气血、14 万～25 万攻击、2500～3000 技能的五档固定属性，并明确显示 45/120/180 秒试炼时限。
- **试炼引导描述精简** — 引导 NPC 现在只描述自身外貌和所镇守的试炼，不再在 NPC 描述中重复副本、属性页或战斗规则说明。
- **自动校验补全** — 新增真意逻辑与界面流程回归检查；已验证 8 个门派、40 项真意、全部 10 重精确描述、333 个地图房间及生产前端构建。
