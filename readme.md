# MUD 游戏 - 更新日志

## 2026-10-14 · 修复测试服/正式服数据串号（跨服角色渗入本服排行榜）

- **现象** — 玩家反馈测试服与正式服的排行榜数据"互通"：正式服榜单里能看到测试服的角色
- **根因（两处）**：
  - `data/sql.js#getData` 只按 `(userid, id)` 取角色存档，**没有 `sid` 约束**。同一账号在两服都建过角色时（线上实测有 **16 个账号**如此），这条路径可以取到另一服的角色；`getRoles` 本身是正确的（带 `and a.sid=?`），对比之下更明显
  - 世界档案缺少归属自检：跨服访问/转服遗留会把**他服角色写进宿主服的 `data/<sid>/data.js`**，而加载时没有任何剔除逻辑，一旦写进去就永久残留
- **线上实测证据（只读诊断）** — 正式服 `data/200/data.js` 的积分榜混入 **3 个测试服（sid=100）角色**：`问奈何`（第 2，1348926 分）、`古力娜扎`（第 4）、`祭剑魂`（第 7）；反向污染为 **0**，说明是单向渗漏而非档案互抄
- **修复**：
  - `data/sql.js#getData` 支持传入 `server`，按 `(userid, id, sid)` 三重约束查询；**不传时保持旧行为**，供显式跨服/转服流程使用
  - `world/cmd/comm/login.js#loginIn` 登录取档显式传 `WORLD.SERVERID`；`os/util/data.js#getRoleData` 透传 `server`
  - `data/sql.js` 新增 `getLocalRoles(server)`（本服角色清单）
  - `world/extends/data.js#DATA.on_load` 末尾新增按服自检 `sanitize_foreign_stats`：剔除世界档案里不属于本服的榜单记录（主榜 `TOPS`、门派榜 `tops_*` 清空归属占位；`SCORE`、`SC_STATS` 直接剔除）；**取不到角色清单时一律不剔除**，宁可保留也不误删；成功清单缓存 60 秒、失败只做 5 秒短缓存
- **用真实线上档案验证修复** — 正式服精确剔除越界条目（修复后积分榜第 2 名从测试服角色恢复为正式服的「土豆」），测试服**剔除 0 条**（无误伤）
- **回归** — 新增 `tools/test_server_isolation.js`（静态约束检查 + 直接执行真实实现的行为验证 + 冷启动子进程用例，配套 `tools/isolation_fixture.js`），已接入 `npm test`
- **生效方式** — 进程启动加载世界档案时自动清理已存在的越界记录，无需手工改档
