# 技能系统设计文档

> 供AI外包设计技能使用。重点：**如何设计游戏中不存在的新被动效果**。

---

## 一、先搞清楚：两套被动体系

技能系统有**两套完全不同的被动实现路径**，不能混用：

### 路径A：普通公共技能 → 通过 `on_*` 钩子 + `add_status` 实现

```
技能文件 (world/skill/xxx.js)
  ├─ query_prop(lv)           学会即生效的固定属性
  ├─ query_enable_prop(lv)    装备后生效的属性
  ├─ on_before_attack()       攻击前钩子
  ├─ on_attack()              命中时钩子（返回附加伤害）
  ├─ on_attack_over()         攻击结束后钩子
  ├─ on_dodge()               躲闪时钩子
  ├─ on_parry()               招架时钩子
  ├─ on_beginfight()          进入战斗时钩子
  ├─ on_new_enemy()           新敌人加入时钩子
  ├─ on_fight_over()          战斗结束时钩子
  └─ pfm: { use() {...} }     主动技能（内嵌 add_status 等）
```

**能力来源**：这些钩子函数内可以调用 `me.add_status()`、`target.add_status()`、`me.do_attack()` 等所有战斗API，实现任意复杂的被动效果。

### 路径B：自创技能(ZC) → 通过 `SKILL.ZC_WORDS` 词条 + `combat.js` 中央处理

```
os/skill/skill.js
  └─ SKILL.ZC_WORDS[]        词条定义（name, prop, value, format）
  
world/extends/char/combat.js
  └─ do_attack()             中央处理 zc_* 属性（嗜血/战神/吸血等）
  └─ recount()               中央处理 zc_focus

world/cmd/skill/zc.js
  └─ create_or_update_skill() 从秘籍创建技能实例
```

**能力来源**：每个 ZC 词条只是一个 `prop → value` 的映射。真正的战斗逻辑在 `combat.js` 的固定位置通过 `this.query_prop("zc_xxx")` 读取。**要新增ZC被动效果，必须同时改 ZC_WORDS 定义 AND combat.js 战斗代码**。

### 核心区别表

| 维度 | 路径A: 公共技能 | 路径B: ZC自创技能 |
|------|---------------|-----------------|
| 被动定义位置 | 技能文件自身的 on_* 钩子 | SKILL.ZC_WORDS + combat.js |
| 灵活性 | 极高，任意JS逻辑 | 有限，只能传一个数值参数 |
| 可配置性 | 固定（每个技能写死） | 可自由组合词条、可升级词条等级 |
| 新被动需求的改动 | 只改技能文件 | 改 ZC_WORDS + combat.js 两处 |
| 状态/Buff | ✅ 可直接用 add_status | ❌ 只能通过 prop 间接影响 |

## 二、公共技能被动设计工具箱

### 2.1 可用API速查

技能文件的钩子函数内可调用以下方法：

```javascript
// --- 自身操作 ---
me.query_skill("skill_id", default)     // 查询技能等级
me.query_prop("prop_name")              // 查询属性值
me.hp / me.max_hp / me.mp / me.max_mp   // 气血/内力
me.gj / me.fy / me.mz / me.ds / me.zj   // 战斗五维
me.gjsd                                 // 攻速(ms)
me.bj                                   // 暴击率
me.fight_type                           // 战斗状态(1=切磋, 2=生死)
me.query_enemy()                        // 当前敌人
me.query_weapon()                       // 当前武器
me.query_weapon_type()                  // 武器类型(WEAPON_TYPE)

// --- 目标操作 ---
target.hp / target.max_hp / ...         // 目标属性
target.query_status("status_id")        // 查询目标状态层数
target.query_enemy()                    // 目标的敌人(溅射用)

// --- 伤害/恢复 ---
me.do_attack({target, gj, mz, ...})    // 执行一次攻击
me.end_attack(target)                   // 结束攻击回合
me.do_recover(hp)                       // 恢复气血
target.damage(value, me, diff_fy)       // 对目标造成伤害(无视闪避招架)

// --- 状态/Buff系统（最强大） ---
me.add_status({...})                    // 给自己加buff
target.add_status({...}, me)            // 给目标加debuff/buff
target.remove_status("id", isall)       // 移除状态
target.clear_downside(true/false)       // 清负面/正面状态
me.query_status("id")                   // 查询状态(返回 {count, ...})

// --- 其他 ---
me.set_temp("key", value, ms)           // 设置临时变量(ms后过期)
me.query_temp("key", default)           // 读取临时变量
Math.random()                           // 随机数
```

### 2.2 add_status() 完整参数

这是实现新被动**最重要的API**：

```javascript
target.add_status({
    id: "unique_id",           // 必填：唯一ID，用于去重/叠加判断
    name: "显示名称",           // 必填
    desc: "描述文字",
    duration: 10000,            // 持续时间(ms)，0=永久

    // 属性增益/减益
    prop: {
        gj: 100,               // +攻击
        gj_per: 10,            // +攻击%
        fy: -50,               // -防御
        gjsd_per: 40,          // +攻速%
        mz_per: 40,            // +命中%
        ds_per: -20,           // -躲闪%
        add_sh_per: 5,         // +最终伤害%
        diff_sh_per: 3,        // +免伤%
        distime_per: -60,      // -冷却%
        releasetime_per: -60,  // -出招时间%
        // ... 任意合法属性名
    },

    // 控制效果
    is_busy: true,              // 忙乱（不可攻击）
    is_faint: true,             // 眩晕（不可行动）
    is_miss: true,              // 必闪（攻击必被闪）
    is_rash: true,              // 鲁莽（攻击必不被闪）

    // 叠加行为
    override: 0,                // 0=不可叠加(默认) 1=叠层 2=覆盖刷新
    max_count: 10,              // override=1时的最大层数
    count: 1,                   // 每次叠加的层数(默认1)

    // 控制标记
    downside: true,             // 是否为负面效果(可被清除)
    only_combat: true,          // 战斗结束自动清除
    no_diff: true,              // 不可被抵抗属性减免
    no_clear: true,             // 不可被清除技能移除
    no_steal: true,             // 不可被偷取(黯然销魂掌)

    // 消息
    start_msg: "获得状态的消息",
    finish_msg: "状态消失的消息",

    // 定时回调
    on_interval: function(owner, tick_count) {
        // 每 duration 触发一次，tick_count 从1开始
        // 返回 false 可提前终止
    },
    duration_count: 10,         // on_interval 最大触发次数
    on_attach: function(owner) { /* 状态添加时触发 */ },
    on_expire: function(owner) { /* 状态过期时触发 */ },

    // 自定义数据（供 on_interval 使用）
    data: { dps: 500 }
}, from);  // from 可选：debuff的来源者（用于忙乱计算抵抗等）
```

### 2.3 do_attack() 完整参数

```javascript
me.do_attack({
    target: target,           // 必填：攻击目标
    gj: me.gj,                // 攻击力(默认me.gj)
    mz: me.mz,                // 命中(默认me.mz)
    bj: me.bj,                // 暴击率(默认me.bj)

    no_weapon: false,         // true=空手攻击
    no_parry: false,          // true=无视招架
    no_dodge: false,          // true=无法闪避
    no_power: false,          // true=不计算内功附加伤害
    is_throwing: false,       // true=暗器攻击
    no_append: false,         // true=跳过on_attack_over
    no_append_before: false,  // true=跳过on_before_attack
    no_append_target: false,  // true=跳过目标的on_dodge_over/on_parry_over

    attack_msg: "自定义攻击描述",
    attack_before: "紧跟着",   // 连击前缀
    miss_msg: "未命中描述",
    parry_msg: "被招架描述",
    damage_msg: "伤害描述",

    part: target.query_part(),  // 攻击部位
    add_bjsh_per: 50,           // 额外暴击伤害%

    on_dodge: function(target) { },    // 闪避时回调
    on_parry: function(target, isParry) { }  // 招架时回调

    // 注意：gj/mz 会在攻击结束后被修改(如血刀的on_before_attack改动了par.gj)
});
```

## 三、现有钩子调用链（单次攻击流程）

```
1. on_before_attack(me, target, par)     ← 攻击方 weapon技能 和 force技能
2. 闪避判定
   ├─ 闪避成功 → target.dodge_skill.on_dodge(target, me, par)
   │              → par.on_dodge(target)
   │              → 显示 miss 消息
   └─ 未闪避 →
3. 招架判定
   ├─ target.parry_skill.on_parry(target, me, par)   ← 可在此处拦截
   └─ par.on_parry(target, isParry)
4. 未招架 →
   ├─ weapon.do_attack(me, target, par)       ← 武器特殊效果
   ├─ attackskill.on_attack(me, target, par)  ← 攻击技能命中效果，返回伤害
   ├─ me.force_skill.do_force_attack(me, target, par)  ← 内功附加伤害
   ├─ target.force_skill.on_force_parry(target, me, sh, par)  ← 内功减伤
   └─ target.damage(sh, me, diff_fy)          ← 最终扣血
      └─ target.on_damage(me, sh)             ← 受伤回调
5. attackskill.on_attack_over(me, target, par, sh)    ← 攻击后
6. me.force_skill.on_force_over(me, target, par, sh)
7. me.on_attack_over(me, target, par, sh)             ← 角色自身回调
```

**每个 `→` 都是一个可扩展点**。要在某个节点添加新行为，在技能文件里定义对应的 `on_*` 函数即可。

## 四、设计新被动的实战模板

### 模板1：攻击时触发效果（最常见）

在技能文件中定义 `on_before_attack` 或 `on_attack` 或 `on_attack_over`：

```javascript
// 示例：攻击时根据自身血量提升攻击力
this.on_before_attack = function(me, target, par) {
    var hpRatio = me.hp / me.max_hp;
    if (hpRatio < 0.5) {
        var bonus = (0.5 - hpRatio) * 2;  // 0~100%
        par.gj = parseInt((par.gj || me.gj) * (1 + bonus));
    }
};
```

### 模板2：命中后给敌人上debuff

```javascript
// 示例：命中后使敌人持续掉血（流血）
this.on_attack_over = function(me, target, par, sh) {
    if (sh > 0) {
        target.add_status({
            id: "my_bleed",
            name: "流血",
            desc: "每秒受到伤害",
            duration: 3000,
            max_count: 5,
            count: 1,
            downside: true,
            override: 1,
            prop: { fy_per: -2 },
            data: { dps: me.gj * 0.1 },
            duration_count: 3,
            on_interval: function(owner, tick) {
                owner.add_hp(-this.data.dps);
            }
        }, me);
    }
};
```

### 模板3：进入战斗时获得buff

```javascript
// 示例：战斗开始时获得护盾
this.on_beginfight = function(me, target) {
    me.add_status({
        id: "my_shield",
        name: "护体真气",
        duration: 30000,
        prop: { diff_sh_per: 20 },
        start_msg: "$N真气外放，形成护体罡气！",
        finish_msg: "$N的护体真气消散了。"
    });
};
```

### 模板4：防御反击

```javascript
// 示例：招架成功后反击
this.on_parry_over = function(me, attacker, par) {
    if (par.is_parry) {
        me.send_room("$N招架后顺势反击！", attacker);
        me.do_attack({
            target: attacker,
            gj: me.gj * 1.5,
            mz: me.mz
        });
        me.end_attack(attacker);
    }
};
```

### 模板5：条件触发 + 状态计数

```javascript
// 示例：每3次命中触发一次爆发
this.on_attack_over = function(me, target, par, sh) {
    if (sh > 0) {
        var count = me.add_temp("my_combo", 1, 10000);  // 10秒内有效
        if (count >= 3) {
            me.remove_temp("my_combo");
            me.send_room("$N连击达到3次，触发爆发！", target);
            // 追加一次强力攻击
            me.do_attack({
                target: target,
                gj: me.gj * 2,
                mz: me.mz * 1.5,
                attack_msg: "$N蓄力爆发，重重一击！"
            });
        }
    }
};
```

## 六、设计真正新被动：还没人做过的事情

以下是**目前游戏不存在的被动效果**，以及实现思路：

### 6.1 目前缺失的被动类型

| 类型 | 思路 | 实现方式 |
|------|------|---------|
| 受击触发 | 受伤时触发护盾/反伤/加速 | `on_damage` 钩子 |
| 击杀触发 | 杀死敌人时回血/加buff/刷新CD | `on_fight_over` 钩子 |
| 队友相关 | 队友受伤/死亡时触发 | 需新增钩子或房间扫描 |
| 地形相关 | 特定房间类型触发效果 | `me.environment` 判断 |
| 时间相关 | 战斗持续越久越强 | `on_beginfight` 记时间 + `on_before_attack` 算差 |
| 武器克制 | 对特定武器类型增伤 | `on_before_attack` 读 target.query_weapon_type() |
| 属性转化 | 将防御/身法等转化为攻击 | `on_before_attack` 修改 par.gj |
| 牺牲效果 | 消耗气血/内力换取爆发 | `me.add_hp(-n)` + `par.gj *= 2` |
| 吸收转化 | 将受到的伤害转为资源 | `on_damage` 记录 + `add_mp` |
| 光环效果 | 进入房间给所有人buff | `me.environment.items` 遍历 + add_status |
| 连锁反应 | 暴击后触发额外效果 | `par.iscirt` 判断 |
| 濒死触发 | HP低于阈值自动触发效果 | `on_damage` 检查 HP |

### 6.2 示例：实现一个全新的"受击叠加狂暴"被动

```javascript
// 技能文件: world/skill/blade/kuangbaodao.js
this.inherits(SKILL);
this.name = "狂暴刀法";
this.id = "kuangbaodao";
this.grade = 4;
this.can_enables = ["blade"];

// 被动：受伤时叠加"狂暴"层数，每层+攻-防
// 实现：利用CHARACTER.prototype.on_damage 钩子
// 注意：on_damage 是在 character 上定义的，不是 skill 上
// 所以需要在 on_learn 时注册，on_remove 时注销
```

**关键点**：`on_damage` 是 CHARACTER 级别的钩子，不是 SKILL 级别的。如果要实现"学会某技能后获得受击效果"，需要：

```javascript
this.on_learn = function(me) {
    // 保存原有的 on_damage
    me._kb_old_on_damage = me.on_damage;
    me.on_damage = function(attacker, damage) {
        // 先调用原有的
        if (me._kb_old_on_damage) me._kb_old_on_damage.call(this, attacker, damage);
        // 新逻辑：受到伤害时叠加狂暴
        var sk_level = me.query_skill("kuangbaodao", 0);
        if (sk_level > 0 && damage > 0) {
            me.add_status({
                id: "kuangbao_rage",
                name: "狂暴",
                duration: 8000,
                override: 1,
                max_count: 10,
                count: 1,
                prop: { gj_per: 5, fy_per: -3 }
            });
        }
    };
};

this.on_remove = function(me) {
    if (me._kb_old_on_damage !== undefined) {
        me.on_damage = me._kb_old_on_damage;
        delete me._kb_old_on_damage;
    }
};
```

## 七、设计新被动效果的操作清单

无论是外包给AI还是自己设计，给出以下6个信息即可：

1. **效果名称** + **触发条件**
   - 例："受伤时20%概率触发，回复5%气血"

2. **触发阶段**（从第三节的钩子链中选择）
   - on_before_attack / on_attack / on_attack_over
   - on_dodge / on_dodge_over
   - on_parry / on_parry_over
   - on_beginfight / on_fight_over
   - on_damage（需要 on_learn 注册）

3. **效果逻辑**（伪代码即可）
   - 修改属性 → `add_status(prop: {...})`
   - 造成伤害 → `do_attack(...)` / `damage(...)`
   - 恢复 → `do_recover(...)`
   - 控制 → `add_status(is_busy: true)`
   - 持续伤害 → `add_status(on_interval: ...)`

4. **数值范围**：基础值 + 随等级成长公式

5. **是否可叠加**：层数上限 + 每层增减量

6. **已有技能中是否有类似效果**（参考第五节避免重复）

    });

        // 你的被动逻辑
    }

this.pfm = {

    "$N挥动$W向$n的$l刺去",
    "$N剑光一闪，$W直取$n的$l"

## 两种被动对照速查

```
我要设计一个新被动效果：

├─ 是给固定技能用的？
│   └─ YES → 路径A：在技能文件里写 on_* 钩子
│       ├─ 修改战斗属性 → add_status(prop: {...})
│       ├─ 命中触发额外攻击 → on_attack_over → do_attack
│       ├─ 受伤触发 → on_learn 里覆盖 me.on_damage
│       ├─ 招架/闪避触发 → on_parry_over / on_dodge_over
│       └─ 持续伤害/治疗 → add_status(on_interval: ...)
│
└─ 是给自创技能(ZC)用的？
    └─ YES → 路径B：改两处
        1. SKILL.ZC_WORDS[] 添加词条定义
        2. combat.js 的 do_attack()/recount() 添加效果处理
```
