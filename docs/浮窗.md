# 浮窗接口（me.popup）

新功能需要弹出选择菜单、二级菜单、带说明的列表时，一律用 `me.popup(选项)`，不要手拼 `{type:"cmds",...}` 字符串，也不要再往 `send_commands` 里堆参数。

实现见 `os/char/user.js` 的 `USER.prototype.popup`，测试见 `tools/test_popup.js`。

## 选项

| 选项 | 说明 |
|---|---|
| `text` | 浮窗顶部的说明文字，支持颜色标签 |
| `buttons` | 底部按钮：`[[命令, 名字], ...]` 或 `[{cmd, name}, ...]` |
| `rows` | 富内容行。每行可以是字符串（纯说明），或 `{text, buttons:[[命令, 名字], ...]}`（说明加行内按钮） |
| `html` | 直接给一段 HTML，排在 `rows` 前面。行内按钮用 `UTIL.popup_btn(命令, 名字)` 生成 |
| `back` | 返回按钮，放在最后一行。可以是命令字符串（名字默认「返回」），也可以是 `[命令, 名字]` |
| `size` | 尺寸档位，如 `"lg"` |
| `persistent` | 点按钮后浮窗不自动关闭，适合需要反复操作的面板 |
| `feedback` | 浮窗内的提示行，比如失败原因，不往主消息栏推 |

命令和名字里有引号、换行都会自动转义。

## 例子

一级菜单（选项按钮）：

```js
me.popup({
    text: "你目前已掌握" + n + "个药方，要炼制哪个级别的丹药？",
    buttons: [["lianyao g1", "炼制一级丹药"], ["lianyao g2", "炼制二级丹药"]]
});
```

二级菜单（每行一个按钮加说明，底部返回）：

```js
me.popup({
    rows: [
        "你目前可以炼制以下丹药：",
        UTIL.popup_btn("lianyao 2", dan.color_name) + "需要材料：" + mats,   // 按钮在前
        { text: "说明在前", buttons: [["lianyao 3", "炼制"]] }               // 按钮在后
    ],
    back: "lianyao",
    size: "lg"
});
```

## 随从

随从被主人用 `dc <随从> <命令>` 指挥时，随从身上调用 `popup` 会自动弹给主人。

按钮命令要自己带上 `dc <随从id>` 前缀，否则主人点按钮时执行的是主人自己的命令。炼药的写法可以参考 `world/cmd/obj/lianyao.js`。

## 公共组件

- `UTIL.popup_btn(命令, 名字)`：行内按钮的 HTML。
- `UTIL.popup_row(说明, [按钮HTML, ...])`：一行，样式是 `src/floatdialog.js` 里的 `.zc-row`。

自创武学菜单（`world/cmd/skill/zc.js`）也用这两个组件。
