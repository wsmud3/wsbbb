# 装备属性 ID 参考文档

## 装备属性格式

装备在 `prop: {}` 中定义属性，正值表示增益，负值表示减益。时间类属性正值=减少(增益)，负值=增加(减益)。

示例（来自 `world/obj/eq/lv2/wf_xiangnang.js`）:
```js
prop: {
    ds: 44,               // 躲闪 +44
    releasetime_per: 10,  // 绝招释放时间 -10%
},
```

## 三、时间类属性（毫秒）

正值=减少时间(增益)，负值=增加时间(减益)。显示时转换为秒。

| ID | 中文名 | 说明 | 示例 |
|---|---|---|---|
| `distime` | 绝招冷却时间 | 冷却时间固定减少 | `distime: 500` → -0.5秒 |
| `releasetime` | 绝招释放时间 | 释放时间固定减少 | `releasetime: 300` → -0.3秒 |
| `gjsd` | 攻击速度 | 攻击间隔固定减少 | `gjsd: 200` → +0.2秒 |
| `busy` | 忙乱时间 | 忙乱持续时间(正值=增加，为负面) | `busy: -500` → -0.5秒 |
| `diff_busy` | 忽视忙乱 | 忽视忙乱时间固定值 | `diff_busy: 300` → +0.3秒 |
| `diff_downside` | 负面状态抵抗 | 负面抵抗时间固定值 | `diff_downside: 200` |

## 十一、属性值正负规则汇总

| 属性类别 | 正值含义 | 负值含义 |
|---|---|---|
| 基础战斗属性 (gj/fy/mz/ds/zj/max_hp/max_mp/add_sh/diff_sh) | 增益 | 减益 |
| 百分比战斗属性 (_per结尾) | 增益 (显示+X%) | 减益 (显示-X%) |
| 时间属性 (distime/releasetime/gjsd/diff_busy/diff_downside) | 减少时间=增益 (显示+秒) | 增加时间=减益 (显示-秒) |
| busy (忙乱时间) | 增加时间=负面 (显示+秒) | 减少时间=增益 (显示-秒) |
| 消耗类 (expend_mp_per/distime_per/releasetime_per) | 增加消耗=负面 | 减少消耗=增益 |

## 快速参考：无被动装备常用属性

对于没有被动的普通装备，通常使用以下属性：

```js
// 最常用的装备属性组合
prop: {
    gj: 数值,        // 攻击
    fy: 数值,        // 防御
    mz: 数值,        // 命中
    ds: 数值,        // 躲闪
    zj: 数值,        // 招架
    max_hp: 数值,    // 气血
    max_mp: 数值,    // 内力

    // 百分比加成（与上面搭配使用）
    gj_per: 数值,
    fy_per: 数值,
    mz_per: 数值,
    ds_per: 数值,
    zj_per: 数值,
    hp_per: 数值,

    // 特殊
    bj_per: 数值,           // 暴击率
    add_sh_per: 数值,       // 最终伤害%
    diff_sh_per: 数值,      // 伤害减免%
    gjsd_per: 数值,         // 攻速%

    // 绝招相关
    distime_per: 数值,      // 冷却%
    releasetime_per: 数值,  // 释放时间%
}
```
