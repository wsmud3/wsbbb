# 原版副本数据采集与自动运行

`tools/mush_ws_capture.user.js` 是运行在 `mush.aize.org` 登录页面中的用户脚本。它会记录页面已经收到/发出的 WebSocket 与游戏接口消息，并可调用原版副本流程自动跑图；不会读取账号密码、Cookie 或向服务器发送脚本之外的隐藏请求。

## 安装与面板检查

1. 在 Tampermonkey 中删除或停用旧版同名脚本，然后把仓库内 `tools/mush_ws_capture.user.js` 的完整内容重新安装并启用。
2. 确认脚本匹配 `http://mush.aize.org/*` 或 `https://mush.aize.org/*`，重新打开原版页面并硬刷新一次。
3. 页面右上角应出现 **WSBBB 原版采集器 1.1** 面板。面板显示“自动流程 未安装”时，说明自动副本依赖还没有加载，不影响消息记录。
4. 若仍没有面板，在原版页面控制台执行：

   ```js
   typeof MUSH_CAPTURE
   MUSH_CAPTURE && MUSH_CAPTURE.status()
   document.getElementById("wsbbb-capture-panel")
   ```

   第一条应为 `"object"`，第三条应返回面板元素；若为 `undefined/null`，说明脚本没有匹配当前页面，检查 Tampermonkey 的启用状态和 URL 后再刷新。

## 自动采集

自动按钮依赖原版公开的 `wsmud_Raid` 用户脚本，它提供 `ToRaid.perform` 和 `@fb` 副本流程。请在同一个 Tampermonkey 中安装并启用该脚本，再刷新原版页面；面板状态变为“自动流程 就绪”后才能运行自动按钮。

- **运行一个**：输入副本编号，例如神龙教输入 `8`。
- **自动采集公开副本**：按顺序运行从神龙教开始、公开流程脚本支持的副本。角色需要具备自动战斗能力，运行期间不要手动输入移动或战斗指令。
- **停止**：请求停止当前自动流程。
- **标记**：在关键房间或 NPC 前添加时间标记，方便后续从导出的消息中定位。
- **导出**：下载 `mush-capture-*.json`，将文件交给维护者转换为仓库地图/NPC 数据。

当前公开流程编号为：`8-23`、`26`、`30`。仓库中更后面的特殊副本（例如黑木崖、缥缈峰、天龙寺、血刀门、古墓派、净念禅宗、慈航静斋、战神殿）不在公开 `@fb` 流程中，需要先采集一个已支持副本的完整样本，再为这些副本编写对应自动流程。

## 安全与采集范围

采集文件可用于重建房间名称、描述、出口、动态出口、NPC、NPC 属性/技能、战斗触发、掉落提示以及副本完成/退出流程。只会保存页面实际观察到的消息，不会臆造服务器未发送的数据。

不要把账号密码、Cookie 或其他登录信息发到聊天中。采集文件可能包含角色名和战斗记录，分享前请先检查内容。

在浏览器控制台中也可以使用：

```js
MUSH_CAPTURE.mark("神龙教-开始");
MUSH_CAPTURE.count();
MUSH_CAPTURE.export();
MUSH_CAPTURE.runDungeon(8, 0);
MUSH_CAPTURE.runAll();
```
