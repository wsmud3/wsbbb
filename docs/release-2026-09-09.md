# 本轮交付与 OS 变更说明

本说明覆盖 Luna 待验收成果、Astra 补修，以及用户批准的外部报告新增安全/崩溃问题。9月6日、7日文档是阶段草稿，发生冲突以本说明及实际代码为准。

## OS 做了什么

| 模块 | 改动 | 对玩家/运维的作用 |
|---|---|---|
| 心跳 | 玩家、房间、NPC 使用快照遍历并逐对象隔离异常 | 某个对象报错或退出不再让后面的玩家/NPC 跳过本轮处理。 |
| 登录生命周期 | 修复重连双重否定；角色切换保留连接；读取完成才登记；失败清理；同连接加载防重入 | 减少重连卡住、切角色掉线、半初始化角色被保存的问题。 |
| 存档 | 合并重叠全量保存；角色同步数据库提交；全局文件写入排序；下线写入失败保留恢复快照 | 避免旧保存覆盖新进度、失败角色拖累其他角色，保存失败可查可恢复。 |
| 关服 | 等待全量保存和待完成下线保存；失败不报告正常退出 | 运维能识别未成功保存，不能把“收到关闭信号”当保存完成。 |
| 备份/加载 | 文件名含服号和随机后缀；备份按服隔离；主备档均坏拒绝空档启动；禁止在线直接回滚 | 减少备份互相覆盖、错误空档启动和内存再次覆盖回滚文件。 |
| 奖励 | 山外山背包及永久领取凭据在同一角色 SQL 写入；失败回滚物品，遗留 pending 可补发 | 降低“已领取却无物品”、崩溃重复领取和补发永久卡住风险，旧领取记录保留。 |
| 通信 | 修复分包/粘包/分片与中文边界；代理验证真实101、限制握手等待并双向清理 | 减少半条指令、断线残留和后端拒绝却伪装连接成功。 |
| 对象数据 | NPC 技能/状态/掉落和装备词条数据分离；禁用 NPC 安全跳过 | 防止同模板对象互相改动和空克隆崩溃。 |
| 热路径 | 删除每次回血同步写文件及堆栈采集 | 消除固定路径写盘异常，并去掉这条确定多余的同步 I/O。没有量化整体提速。 |
| 数据库连接 | 预编译语句缓存归属连接，关闭/重开清理；首次建表事务化 | 防止复用已关闭连接的 statement，首启失败不再假报成功。 |
| 审计/权限 | 认证命令日志脱敏、HTTP/WS 验证当前账户；后台路径范围及请求体限制 | 降低登录凭据泄露和后台越界写删风险。 |

未宣称完成的性能工程：500人压测、P50/P95 延迟基准、统一计时器所有者、生产缓存零 stat、全协议慢客户端背压与账号公平调度。它们仍须测量并分批推进，不能以本次稳定性修复冒充完成。

## 玩家兼容与运维注意

- 玩家真意/装备/技能进度、山外山最高层及旧领取记录不清零；不调整试炼 NPC 数值和已经确认的溅射/必中规则。
- 旧登录凭据需要重新登录一次。公开找回密码保持关闭，图片验证码不是独立身份证明。
- SESSION_SECRET 与 ADMIN_IPC_SECRET 至少16字符，应替换为独立随机值。已有账号密码不自动改动；请人工核查历史默认管理员是否仍使用弱密码。
- INITIAL_ADMIN_PASSWORD 仅供全新数据库引导；未配置足够长密码时初始化管理员为禁用状态。它不会重设现存管理员。
- 后台文件编辑仅面向内容目录；OS/API/config/.env 等通过正常代码发布或服务器管理维护。
- 自动发布使用 flock、SQLite 一致性备份、候选资源校验、锁定依赖安装、项目 PM2 重载和逐服务 SHA 检查；失败退出非零，不自动覆盖数据库。失败后的依赖/进程排障需人工处理，不能在线恢复旧数据库。
- 更新 pull.sh 的第一轮仍可能由已经启动的旧脚本执行；下一轮才完整采用新门禁。未在用户服务器上更换 cron 或执行部署。
- 前端先在独立临时目录构建成功，再复制资源及切换入口；构建失败不会先清空 www。保留上一版已发布哈希，便于仍打开的页面加载资源。
- TRUST_PROXY 仅在确认可信反向代理网段时设置；不要用全信任任意来源来绕过限流。

## 可重复验证

- `npm test`：原有逻辑与静态回归、32项独立验收、SQLite/HTTP/WS 集成、新增报告修复行为测试。
- `npm run build`：生产前端构建并检查 JS/CSS 引用。
