# 华山·独孤剑冢 真意禁地参考（其他门派照此改版）

华山是新版真意禁地的第一个完成品（2026-11-20 定稿）。其余七派仍是旧版：五道小数值真意 + 十重修炼，见 `docs/zhenyi-system.md`。改其他门派时，以本文为模板。

## 1. 设计思路

- **一派一道真意，做超模机制，不做数值**。多道小数值真意相当于多一个绝招，不如一道真正改变玩法的机制。华山的真意是「无剑·无招」：不拘兵器施展剑法绝招。
- **真意不分重数**：通关即领悟，不升级、不扫荡升级、不发悟痕。
- **试炼是一条闯关路线**：禁地里的机关和化身战斗交替出现。解开一处机关，这一关的化身就现身；击败化身，才能继续往深处走。五关全过即领悟真意。
- **故事贯穿始终**：每一关对应门派先贤的一段经历。华山的五关是独孤求败的利剑、软剑、重剑、木剑、无剑五个境界，机关和战斗都围绕这段经历设计。
- **最后一关是专属 boss**：面板和机制单独设计，不套通用的系数。

## 2. 入口：云湺山

- 八派禁地合并成一个总入口「云湺山」（`world/area/map/jindi.js`，22 个房间）。它在江湖地图禁地列表第 2 位，介绍是「各大派高手隐居之处」。
- 路线：山脚 → 白云石阶 → 迎客坪 → 松风岭 → 山心石坪。三处平台各分出岔路，每条岔路是一段小路接一处祖师居所。华山的是「樵径 → 剑庐」。
- 在居所点「踏入××」进入本门禁地。只接纳本门弟子，别派点了只提示「前路云雾翻涌……找不到入口」。房间名不带门派前缀。
- 进云湺山要求：有门派、武帝境界、通过武道塔 100 层。
- 本门禁地的第一个房间，往南走回本门居所。

## 3. 剑冢五关

五处机关是 `world/map/jz/` 下的五个房间，五关的考法是 `world/npc/pub/zhenyi_trial.js` 里的模式（mode）。下表的化身气血已乘华山统一的 0.8（`trialHpScale`），攻击已乘对应模式的攻击系数（`GJ_SCALE`）。

| 关 | 机关房间 | 机关 | 考法 | 化身（名字 / 气血 / 攻击 / 时限） |
|---|---|---|---|---|
| 1 利剑问锋 | 利剑阁 | 四面墙的剑痕只有一面合「凌厉刚猛，无坚不摧」：遇到坚石径直穿过。走错扣 15% 最大气血，并重新出题 | `precision`：每 15 秒凝聚剑罡，受到伤害降低 80%，5 秒内连中 3 次可破 | 利剑化身 / 960 万 / 约 14.3 万 / 180 秒 |
| 2 软剑回环 | 软剑阁 | 软剑颤动五次（初颤……末颤），每颤在九宫一处方位亮起微光，按顺序踩对应的篆字砖。踩错扣 10% 最大气血，并重新出题 | `counter`：剑势每 5 秒叠一层，每层伤害 +8%，最多 10 层；绝招命中后 4 秒内用普攻打中，卸去全部剑势 | 软剑化身 / 1200 万 / 约 12.4 万 / 180 秒 |
| 3 重剑负山 | 重剑殿 | 献祭 30% / 50% / 70% 气血开门，化身气血相应为 100% / 80% / 60%。打赢之前可以改选 | `burst`：每 5 秒回复 2% 气血，被绝招打中后 10 秒内不能回；每 20 秒蓄力重击（你最大气血的 20%），蓄力时用绝招打中可打断，也可以躲闪 | 重剑化身 / 1440 万 × 献祭比例 / 约 10.9 万 / 120 秒 |
| 4 木剑守拙 | 木剑阁 | 卸下兵器，空手盘坐。拿着兵器盘坐扣 5% 最大气血 | `insight`：开战 3 秒后判定，先天悟性 × 后天悟性须达到 10 万，不够则领悟失败、送出试炼；够的话接一剑，伤害为最大气血 100%，只受伤害减免影响，接下即过，接不下留 1 点气血、判定失败 | 木剑化身 / — / 不出手 / 60 秒 |
| 5 无剑胜有 | 无剑虚空 | 与独孤求败 NPC 对话，浮窗二选一：谦卑线或骄傲线（见下） | `jianmo`：剑魔专属机制（第 4 节） | 剑魔 独孤求败 / 4000 万 / 30 万 / 不限时 |

- **第一到第三关的化身共用规则**：用华山首领的武功，技能 2500～3000 级；自带 70% 忽视防御、50% 忽视忙乱；攻击间隔 1 秒；单次扣血超过它最大气血 1.2% 的部分只按 5% 计入。剑魔取消了这个扣血上限。
- **解机关后**：弹出「开启试炼」。没击败化身就走不了北面出口，回到机关处会再弹一次。
- **开场和结束**：剑冢五关开场不念规则、不提示精力消耗；完成后直接送回机关房间，消息栏提示「你已完成试炼」。所有门派的试炼都改为完成即离场。
- **第五关的两条路线**：
  - 谦卑线：独孤求败以《神雕侠侣》剑冢四剑的铭文点化你，这次到此为止，不领悟真意。你获得「参悟」：1 小时内悟性 +500，练习、学习、打坐效率 +100%。参悟会存档，下线不丢，每天只能拿一次，之后仍可回来改走骄傲线。参悟的后天悟性正好配合第四关的悟性门槛。
  - 骄傲线：直接开始和剑魔的战斗。
- **剑渊谷底**：「紫薇软剑残片」，拾取后获得「紫薇剑意」：5 分钟内受到剑魔的伤害降低 20%。每次进入剑冢都能重新拾取。
- **悟剑石**：盘坐参悟只有剧情作用。

## 4. 剑魔 独孤求败（最终 boss）

- **面板**（`stage` 的 `avatar_stats`，不套攻击、气血系数）：气血 4000 万，内力 5 亿，攻击 30 万，暴击 70%，最终伤害 80%，负面抵抗 80%。头衔「剑魔」为红字。
- **技能**：剑法独孤剑诀（无剑，不可被缴械），招架独孤九剑，内功紫霞，轻功狂风快剑，拳脚劈石破玉拳，均为 3000 级。
- **剑罡**：每 10 秒凝聚一次，持续 5 秒，特殊免伤 +200%，不计入软上限。期间所有伤害（含真实伤害）都被化解，每次提示「独孤求败身上涌现出剑罡，化解了你这一招」。剑罡期间被打中 10 次即破碎，1 分钟内不再凝聚。
- **万剑归宗**：气血降到 80%、60%、40%、20% 时各放一次，令挑战者「迟钝」：攻速 -50%，持续 10 秒。
- **不设时限**。
- **被击倒**：按比试落败处理。双方罢手，挑战者留 1 点气血、不出场；剑魔回满气血，剑罡和万剑归宗重新计。挑战者可以再次出手重打。
- **放弃**：动作栏「完成副本」→ 确认「放弃试炼并离开」→ 算整个剑冢试炼失败，五关进度清零，送到云湺山剑庐。重游时放弃，只结束这次重游。
- 机制常量见 `zhenyi_trial.js` 的 `JIANMO`，面板见 `world/zhenyi.js` 的 `stage(5, …)`。

## 5. 真意与上古传承

- **真意「无剑·无招」**（effect `jz_swordless`）：灭烛见真火，忘剑得神兵。启用后，无论手持何种兵器或空手，都能施展已装备的剑法绝招，包括手动施展、自动出招和幻魔身法随机触发；绝招栏也会列出剑法绝招。实现是 `WORLD.ZHENYI.weapon_free(me, need)`，接在 `pfm.js`、`auto_combat.js`（`init_pfms` / `query_auto_pfm_skills`）、`USER.on_skillchanged`、`busiyinfa.js` 这几处。启用或卸下真意时，会刷新绝招栏和自动出招列表。
- **上古传承技能「独孤剑诀」**（`world/skill/huashan/dugujianjue.js`，grade 6，`is_ultimate`）：江湖界面门派页单列「上古传承」。剑魔用它；玩家可以用残页合成秘籍学习。

  | 项目 | 1000 级 | 上限 |
  |---|---|---|
  | 攻击 | 3000（3 × 等级） | 不封顶 |
  | 攻击间隔缩短 | 0.4 秒 | 1 秒 |
  | 最终伤害、命中 | 10% | 40% |
  | 暴击 | 4% | 10% |
  | 剑意：持续时间 | 7 秒 | 12 秒 |
  | 剑意：最终伤害、命中、招架 | 70% | 100% |
  | 剑来：飞剑持续时间 | 9 秒 | 15 秒 |
  | 剑来：每击真实伤害（攻击力的） | 60% | 100% |
  | 剑意 / 剑来 1000 级内力消耗 | 96390 / 109650 | — |

  - 剑意还会让出招间隔压到引擎下限，并且敌人无法招架。
  - 被动「无剑」：装备为剑法并持剑时，兵刃不可被卸下，缴械类绝招统一走 `CHARACTER.prototype.weapon_locked`。
  - 被动「无我」：剑法命中叠层，每层攻击、命中 +2%（1000 级），最多 10 层。
- **红色技能内力消耗**：绝招基础消耗 = 1630 + 冷却秒数 × 26/3，1000 级时 × 51。冷却 30 秒为 1890，60 秒为 2150。

## 6. 奖励与重温

- **首次通关**：独孤剑诀残页 × 200。领过会记标记 `zy_frw_jz`；更新前已通关的老角色，找独孤求败对话可补领一次。
- **残页**：`book/bc#dugujianjue`，红色技能凑满 500 张合成一本秘籍。
- **重温（扫荡）**：剑道传承殿的 NPC「无名剑」→「重温试炼」，常驻浮窗只有「扫荡一次 / 十次」。每次 10 精力，得玄晶，30% 概率得一张残页；须已通关。次数累计在 `zy_sweep_jz`。
- **易直非兑换**：赌场易直非（能兑换所有副本的那位，`pub/baodi`）列表最前面有「独孤剑冢」，重温次数每 20 次换 1 张残页，已用次数记在 `fbx_spent_zy_jz`。
- **剑冢重游**（测试和回味用）：通关后在利剑阁点「剑冢重游」，可以从第一关重走，或直达无剑虚空再会独孤求败。重游中可放弃；打完第五关自动结束。重游不影响已领悟的真意。

## 7. 代码结构

### 门派配置（`world/zhenyi.js` 的 `DATA.HUASHAN`）

```js
v2: true, trialHpScale: 0.8, no_level: true,        // 不分重数
first_clear_reward: { path, count },                // 首通奖励
sweep: { energy, piece, piece_rate, exchange_cost },// 重温与兑换
puzzles: { 1: "jz/lijiange", ... 5: "jz/wujianxukong" },
list: [ zy(5, "无剑·无招", "剑境", "剑冢五关", "master", [], "jz_swordless") ],  // 一道真意；id 沿用 5，旧档原样保留
stages: [ stage(1, "利剑问锋", "precision", "利剑"), ...,
          stage(5, "无剑胜有", "jianmo", "无剑", { avatar_name, avatar_title, avatar_sword, avatar_stats,
                                                  timeout: 0, no_death: true, quit_to: "jindi/huashan" }) ]
```

- `stage(id, 名, 考法, 简称, opts)`：id 和 `puzzles` 的机关编号一一对应，最后一关通过即领悟 `list` 里的真意。
- `stage` 可选字段：
  - `avatar_name` / `avatar_title`：化身的名字和头衔；
  - `avatar_sword`：化身装在剑法位的技能；
  - `avatar_stats`：固定面板，不套攻击、气血系数；
  - `timeout`：时限，0 为不限时；
  - `no_death`：被击倒按比试落败处理；
  - `quit_to`：可以主动放弃，并指定放弃后送到哪里。

### 关键函数（都在 `world/zhenyi.js`，导出在 `WORLD.ZHENYI`）

| 函数 | 作用 |
|---|---|
| `findTrial` | 有关卡的门派按关卡查，其余门派查真意本身 |
| `stageCleared` / `puzzleSolved` / `puzzleGate` / `solvePuzzle`（`no_offer`）/ `offerStage` | 关卡进度、机关状态、关门、解机关后弹出开启试炼 |
| `startTrial` / `completeTrial` / `failTrial` / `quitTrial` / `returnFromTrial` | 开启、完成即离场、失败、放弃（送到 `quit_to`） |
| `preventDeath` | 由 `USER.die` 调用，不死关卡在这里拦下死亡 |
| `startReplay` / `offerReplay` | 剑冢重游 |
| `sweepStages` / `offerSweep` / `grantFirstClearReward` / `claimFirstClearReward` | 重温扫荡、首通奖励与补领 |
| `grant_timed_buff` / `restore_timed_buffs` | 会存档的限时增益（参悟），登录、重连时按剩余时间重挂 |
| `migrate` | 旧档迁移：领悟过的旧真意折算为对应关卡已过；禁地列表位迁移（`jd_layout`） |

禁地公共地图默认只放行试炼引路人一种 NPC。新增对话类 NPC，要加进 `allowPublicNpc` 的白名单。

### 本次改版涉及的引擎机制

- **状态自带战斗回调**：绝招的效果要能随绝招走（融合进自创武学也生效），就写在它挂的状态上。见 `docs/skill_authoring.md`。
- **被动执行上下文**：`CHARACTER.passive_depth`，用来区分绝招自己挂的状态和被动挂的状态。
- **批量移除状态后重算控制标志**：`_recalc_ctrl_flags`。
- **会存档的限时增益**：到期时间存在会存档的 temp 上，上线时恢复状态。
- **登录时不删除暂未注册的自创武学记录**。

## 9. 移植到其他门派的清单

1. **定主题**：选一段门派先贤的故事，拆成五个阶段，最后一段对应真意本身，比如武当太极、少林达摩面壁。
2. **定真意**：一道超模机制，不做数值。实现要能接进现有入口（施展、自动出招、绝招栏等），启用或卸下时刷新相关列表。
3. **写五处机关**：提示要隐晦，用武侠笔调，不写「第1颤」这类说法，不直接写出做法；玩家要结合禁地里的铭文、景物来推理。错误要有代价（扣气血、重新出题）。
4. **配五个考法**：可以复用 `precision`、`counter`、`burst`、`insight`，或按主题新增；最后一关写专属 boss，参照 `jianmo`。
5. **配奖励**：首通奖励、重温扫荡、易直非兑换，配上传承技能的残页。
6. **建入口**：在云湺山对应的祖师居所接入本门禁地。
7. **旧档迁移**：旧真意折算为关卡已过；启用中的旧真意要卸下。
8. **跑测试和模拟**：`npm test` 加上模拟胜率。剑魔目前偏难，改动前 8 场 1 胜，换成独孤剑诀后 8 场全败；各门派最终 boss 的目标难度要和用户确认。

## 10. 约定（用户定下的规则）

- 玩家可见的技能和物品说明只写当前数值，不写公式。
- 战斗提示不写属性数值、层数和系统术语；伤害数字可以保留。
- 只有写在技能面板里的才算被动；绝招说明里的效果都要随绝招走。
- 免伤类 buff 用 `diff_sh_per2`（特殊免伤），在软上限之后叠加。
- 「侠客岛」保留给将来的副本，不要拿来命名别的东西。
