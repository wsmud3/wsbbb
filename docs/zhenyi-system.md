# 门派真意系统

## 规则

- 武帝境界且已通过武道塔 100 层后，自动解锁当前门派禁地；登录、打开江湖地图和拜师时都会补发旧角色权限。
- 只能进入当前门派禁地。移动层与区域入口均会校验，避免直传、旧存档房间等绕过方式。
- 每个门派有五项试炼。进入禁地不耗精力，挑战或扫荡每次消耗 20 点精力；每项试炼每天挑战与扫荡合计最多 10 次。
- 首次完成试炼领悟对应真意。后续挑战奖励玄晶、对应悟痕，并有概率获得已领悟真意的额外悟痕。
- 真意最高 10 重，升级消耗玄晶与对应悟痕；品质档位就是真意的主要强度层级，重数只负责同品质内的小幅成长。同一时间只能启用一项，且仅能在非战斗状态切换。
- 判师会遗忘原门派全部真意、等级和悟痕；更新前遗留的异门真意也会在登录迁移时清理。
- 真意只强化本门技能，任何 `grade >= 6` 的红色技能均被配置校验和运行时校验双重排除。
- 真意面板和战斗结算共用 `valuesFor` 生成的整数值；伤害、减伤、回复、命中和忽视防御均按百分比展示与结算，控制时间按整秒展示与结算。
- 试炼化身不再读取玩家属性后倍乘，而是沿用旧禁地 NPC 的五档固定量级：1200 万至 3000 万气血、14 万至 25 万攻击、2500 至 3000 技能等级。爆发试炼限时 120 秒，生存试炼坚持 45 秒，其余限时 180 秒。
- 八处公共禁地只生成五名正式试炼引导 NPC，旧敌人脚本保留作数值基准但不再生成。更新前因热更新遗留的 `zy_trial_active` 会在打开系统或重新挑战时自动核验并清除。

## 平衡

各门派通过 `world/zhenyi.js` 中的 `balance` 系数进行差异化补强。华山、丐帮、逍遥等当前强势门派系数较低；峨眉、杀手楼、素女道等弱势门派系数较高。品质档位系数为 1.00、1.20、1.40、1.60、1.80、2.00，且全部结果四舍五入取整。数值仍应结合线上战斗数据继续微调。

## 管理与校验

- 玩家命令：`zhenyi`、`zhenyi active <id>`、`zhenyi challenge <id>`、`zhenyi sweep <id> <count>`、`zhenyi upgrade <id>`。
- 配置、奖励、升级与战斗效果的唯一数据源：`world/zhenyi.js`。
- 提交前执行 `npm run validate:zhenyi`，校验八门派共 40 项真意、PFM 键、门派归属、grade 6 禁令、整数效果、忽视防御单位、残留试炼自愈、固定 NPC 档位、旧 NPC 过滤以及地图文件完整性。
