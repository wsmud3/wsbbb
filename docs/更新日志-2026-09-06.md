# 更新日志（2026-09-06）

> 阶段交付草稿，非最终验收记录。其中密码恢复、存档与发布方案已被9月9日补修替代；以 `release-2026-09-09.md` 为准，不按本草稿开放密码恢复。

## 稳定性与玩家体验

- 修复 WebSocket 在 TCP 拆包时提前执行半条指令的问题；补充粘包、分片、中文消息和超长帧的边界处理。
- 修复双方拥有反震效果时可能递归溢出、战斗中断的问题。反震伤害只结算一层，不改变普通伤害、击杀和既有技能必中规则。
- 修复真意命中加成在闪避/招架判定之后才生效的问题；命中准备与伤害增幅分离，单次真意标记不会重复消耗。
- 修复真意追加忙乱只写入属性表、实际不能限制行动的问题，改为使用状态系统的运行标记。
- 修复自创词条升级的秘籍、技能、部位和词条未完整关联校验，以及超大等级输入造成长时间同步循环的问题。
- 修复山外山一次性奖励在物品创建/入包失败后仍被记录为已领取的问题；奖励组支持回滚并保留待领取记录，重登后可重试。
- 山外山的已挂载属性改为运行态记录，避免角色重登或重算属性时重复扣除。
- 修复前端请求回调在业务回调抛错时重复执行；增加超时、取消和非 JSON 响应处理。
- 修复快速重连时旧 WebSocket 消息更新新连接界面的问题。
- 找回密码流程现在要求有效验证码；转移角色手机号查询接口改为必须配置服务端令牌。

## 管理与存档安全

- 管理接口最低权限不再因测试服默认配置降为普通账号等级；动态 API 不再暴露基类内部方法，`/reload` 需要管理员或独立令牌。
- 会话凭证增加服务端时间有效性检查，CORS 仅允许同源、本机应用或显式配置来源。
- 存档加载只对已知山外山损坏字段做定向迁移；合法文本中的 `[object Object]` 不再被全文替换。
- 批量保存逐个报告角色错误，备份改为一次完整、转义安全的 JSON 文件；保存失败会向上层返回失败。
- 自动部署增加互斥锁和备份失败阻断；健康检查失败只回滚代码，不在线覆盖玩家数据库。数据库恢复必须在停服的人工流程中执行。

## 兼容说明

- 已有角色的真意、技能、自制装备、山外山最高层和已领奖励记录保留。
- 旧版山外山临时属性快照会被清理；角色重新进入山外山时根据当前选择重新挂载。
- 找回密码页面增加图片验证码；若部署环境尚未提供外部恢复验证码服务，需按页面提示走人工恢复流程。
- 本次没有调整试炼 NPC 属性、技能本身的必中/条件必中设计、溅射规则、自制装备词条上限或真意数值。
- 修复角色 ID 为字母数字字符串时被批量保存校验误判的问题，正常下线与自动保存不再静默跳过角色。
- 将 `npm test` 接入完整的离线回归套件；山外山端到端脚本改为默认关闭，并强制显式指定隔离数据库与角色 ID 文件，禁止误写正式玩家数据。
