# 新禁地方案：独孤剑冢

## 一、背景

### 游戏内已有关联

| 已有内容 | 位置 | 关联 |
|---------|------|------|
| 独孤九剑 | `skill/huashan/dugujiujian.js` | 华山派绝学，"为独孤求败所创" |
| 独孤九剑·真义 | `skill/sword/dugujiujian2.js` | 进阶版 |
| 华山论剑副本 | `fb30.js`（hslj），五绝齐聚 | 剑冢入口可设在华山论剑绝壁之下 |
| 华山派 | `area/map/huashan.js`，可加入门派 | 独孤九剑的传承之地 |

游戏里独孤九剑有两本、华山论剑有五绝，但**独孤求败本人的剑冢从未出现**——这是最该补上的禁地。

### 背景故事

> 剑魔独孤求败，纵横江湖三十余载，杀尽仇寇，败尽英雄，欲求一败而不可得。晚年隐于华山深谷，将其一生剑道感悟与四柄佩剑埋于一处，是为**剑冢**。
>
> 他在冢前留字：「剑分五境——利剑无意，软剑无常，重剑无锋，木剑无俦，无剑无招。」五境之中，藏有剑魔毕生剑意。能破五境者，可得剑魔衣钵。
>
> 华山论剑的绝壁之下，云雾终年不散。直到最近一场山崩，崖壁上露出一道裂口，剑气从中冲天而起，照亮了半个华山。五绝闻讯而至，却无一人能踏入剑冢半步……
>
> 江湖震动。**剑魔之冢，终于重现天日。**

## 三、五剑境界房间

```
               [无剑境]          ← 独孤剑意残影（BOSS）
                  ↑
               [木剑境]          ← 无武器战斗
                  ↑
               [重剑境]          ← 献祭气血开门
                  ↑
               [软剑境]          ← 踩踏石台序列
                  ↑
               [利剑境]          ← 观察房间找正确出路
                  ↑
            [剑冢入口]           ← 独孤求败留字石碑
```

**核心设计理念**：每个房间不是"先解密再打怪"，而是**解密本身就是战斗，战斗本身就是解密**。五剑境界层层递进，每进入一层，玩家的战斗方式被迫改变，越来越接近"无剑"的终极境界。

## 四、各房间详解

### 0. 剑冢入口 `jz/rukou`

**描述**：
> 华山绝壁之下，一道被山崩撕开的裂缝直通山腹。入口处立着一块天然石碑，上面以指力刻出数行大字，铁画银钩，霸气凛然。历经千年风霜，字迹仍清晰可辨：
>
> 「纵横江湖三十余载，杀尽仇寇，败尽英雄，欲求一败而不可得。呜呼！群雄束手，长剑空利，不亦悲夫！」
>
> 落款：**剑魔独孤求败**。

**机制**：
- `set_item("jz_shibei", "独孤求败石碑", "碑文入石三分，指尖划过时隐有剑鸣。", ["参悟碑文"])` — 参悟后获得提示：五剑境界的核心理念
- `add_action("enter_jz", "踏入剑冢", ...)` — 给玩家施加「剑冢试炼」状态（全属性 -15%），这是全局压制，随境界突破逐步解除
- 石碑前有一个隐藏小测试：`add_action("touch_swordmark", "轻触碑文剑痕", ...)` — 提示「剑意未散，你感到一股凛冽剑气从指尖窜入体内」

**设计意图**：进入前先打压玩家属性，造成为何千年来无人能破的氛围。每突破一个境界解除一部分压制，最终战完全解除。

---

### 1. 利剑境 `jz/lijian`

**主题**：「利剑无意，凌厉刚猛，无坚不摧。」—— 少年时用的第一柄剑，以锋锐取胜。

**描述**：
> 第一座剑冢。一柄青光闪闪的利剑斜插于石台之上，剑身薄如蝉翼，刃口隐现寒芒。四周石壁上满是剑痕，深浅不一，似是有人在此试剑千万次。你注意到，每一条剑痕的起手和收势略有不同，似乎在暗示什么……

**谜题：观察找路**

房间有 4 个出口（东/南/西/北），但描述中只暗示了正确的那个：
- 石壁上的剑痕在某一面墙上特别密集
- 那道墙的剑痕最深处隐约透出光亮
- 玩家需要通过**阅读房间描述**来发现线索，使用 `add_action("examine_wall", "检查石壁", ...)` 逐面检查

选错出口 → 剑意反噬，`me.damage2(me.max_hp * 0.15)`，提示「剑气逼退了你，这不是正确的方向」
选对出口 → 进入软剑境

**战斗：利剑剑灵**

同时，石台上的利剑会化作剑灵攻击玩家。这个 NPC 的特性：
- 纯粹的物理高攻，没有任何花哨技能
- 但攻速极快，模拟「利剑凌厉」的感觉
- 破防属性高，克制高防御玩家
- 击败后 → 利剑剑意消散，玩家解除第一层压制（全属性回升 3%）

**新鲜在哪**：玩家需要在战斗中抽空观察房间、寻找出路。不是战斗完了再解密，而是边打边解密。

**使用机制**：`add_action` ×4（四面墙 + 检查）、`set_npc`、`on_attack_over`、`damage2`、观察型谜题

---

### 2. 软剑境 `jz/ruanjian`

**主题**：「软剑无常，柔中带刚，变化万千。」—— 第二柄剑，以变化取胜，但也因此误伤义士，被独孤求败弃之深谷。

**描述**：
> 第二座剑冢。一柄紫薇软剑横放在石台上，剑身柔软如绸，在无风的洞中却自行颤动不休，发出嗡嗡剑鸣。石台周围的地面上散布着九块大小不一的青石砖，每块砖上都刻着一个古字。软剑的震动似乎与这些石砖产生了某种共鸣……

**谜题：序列踩踏**

地面 9 块青石砖，对应独孤九剑的九式。玩家必须按照正确顺序踩踏：
- 使用 `add_action("step_1", "踏上第一块石砖", ...)` 到 `add_action("step_9", ...)`
- 正确顺序隐藏在两处线索中：
  - 软剑震动的频率不同（观察描述）
  - 石碑参悟时得到的提示
- 踩错 → 软剑震动加剧，`me.damage2(me.max_hp * 0.1)`，序列重置
- 踩对全部 → 软剑停止震动，通道开启

**战斗：软剑剑灵**

软剑剑灵的特性：
- 攻击角度多变，无法被招架（`on_attack_over` 中设置忽略招架）
- 每 10 秒切换一种攻击形态（刺/劈/撩/扫），不同形态用不同技能
- 玩家必须根据剑灵当前形态切换自己的应对方式
- 击败后解除第二层压制

**新鲜在哪**：序列谜题 + 变换形态的 BOSS。七重门是方向迷宫，这个是真正的序列解密。

**使用机制**：`add_action` ×9、`damage2`、`set_temp` 跟踪序列、`on_heart_beat` 切换攻击形态

---

### 3. 重剑境 `jz/zhongjian`

**主题**：「重剑无锋，大巧不工。」—— 第三柄剑，玄铁重剑，钝而无锋，却能一剑破万法。

**描述**：
> 第三座剑冢。一柄通体漆黑的玄铁重剑插在巨石之中，剑身宽厚无刃，却散发着令人窒息的压迫感。重剑前方，一道巨大的石门封住了去路。石门上只有一个血红色的掌印凹槽——似乎需要以鲜血为引方能开启。

**谜题：献祭开门**

玩家必须主动消耗气血来开门：
- `add_action("sacrifice", "以血祭剑", ...)` — 输入要献祭的气血量
- 献祭量 >= 当前 HP 的 30% → 石门缓缓打开
- 献祭量 < 30% → 石门纹丝不动
- 献祭量 >= 50% → 石门完全打开，且重剑对你的敌意降低（BOSS 伤害 -20%）
- 这是一个**策略选择**：多献祭 = 战斗更轻松，但起始血量更低

**战斗：重剑剑灵**

重剑剑灵的特性：
- 极慢的攻速（攻击间隔 2 倍），但每次攻击是毁灭性的（伤害 2.5 倍）
- 每次攻击前地面会震动（`on_heart_beat` 提前 3 秒预警），玩家可以用 `add_action("dodge_heavy", "闪避重击", ...)` 尝试躲避
- 躲避成功率 = 轻功等级 / (轻功等级 + BOSS 命中)，由 `Math.random` 判定
- 击败后解除第三层压制

**新鲜在哪**：这是游戏里第一个需要玩家**主动献祭**的机制，而且给玩家选择权（献祭多 vs 少）。重剑的预警闪避也是新的互动形式——不再是被动挨打。

**使用机制**：`add_action`（献祭 + 闪避）、`damage2`（自伤 + BOSS 重击）、`on_heart_beat` 预警、策略选择

---

### 4. 木剑境 `jz/mujian`

**主题**：「木剑无俦，飞花摘叶，皆可伤敌。」—— 第四柄剑，已不滞于物，草木竹石均可为剑。

**描述**：
> 第四座剑冢。石台上只放着一柄朽木削成的木剑，剑身布满裂纹，仿佛一碰就会碎裂。但当你靠近时，木剑上每一道裂纹都透出刺目的剑光。更奇怪的是，你腰间的兵刃竟自行颤抖——不是恐惧，而是共鸣。
>
> 然而此地却没有任何剑灵出现。只有木剑静静地躺在石台上，等着你做出选择。

**谜题：放下武器**

进入此境后，玩家发现：
- 木剑剑灵**不主动攻击**，但如果玩家装备了武器，每 5 秒自动受到剑意反噬（`me.damage2(me.max_hp * 0.03)`）
- 唯一的办法是**卸下武器**（`add_action("lay_down_weapon", "放下武器", ...)` — 将武器移到背包）
- 卸下武器后：
  - 反噬停止
  - 木剑剑灵现身，开始战斗
  - 玩家只能用空手/掌法/内功攻击
  - 木剑剑灵也只有空手格斗能力

**战斗：木剑剑灵**

- 属性等于玩家属性的 70%（木剑本身不强）
- 但玩家没有武器 → 失去武器提供的所有属性和技能加成
- 这是一场**纯内功/拳脚**的较量
- 击败后解除第四层压制，此时「剑冢试炼」debuff 完全消失

**新鲜在哪**：游戏里第一个**强制卸下武器**的机制。考验玩家的内功和拳脚。对于一直依赖武器的玩家来说是全新的挑战。也是对"木剑无俦"哲学的游戏化诠释——不再依赖神兵利器，自身即是剑。

**使用机制**：`add_action`（卸下武器）、`on_heart_beat` 反噬、装备检测、属性缩放的 NPC

---

### 5. 无剑境 `jz/wujian`

**主题**：「无剑无招，无我无相，方为至道。」—— 剑道的终极境界。手中无剑，心中亦无剑。

**描述**：
> 最后一座剑冢。这里空旷得出奇——没有石台，没有剑，甚至没有剑痕。只有无尽的黑暗和绝对的寂静。在这片虚空中央，一道模糊的人影负手而立。你看不清他的面容，也感受不到他的气息。他明明站在那里，却又似乎不存在于天地之间。
>
> 他开口了，声音如千年古井中的回音：「很好。你是千年来第一个走到这里的人。」
>
> 「我一生求一败而不能，今日，你能给我一败吗？」
>
> 话音刚落，人影消散——不是消失了，而是无处不在。四周的空气中，每一粒微尘都在锐利地鸣响。**整个空间，都已化作他的剑。**

**谜题：接受失败**

在战斗开始前，玩家面临一个选择：
- `add_action("accept_defeat", "承认不敌", ...)` — 承认自己不如独孤求败
- `add_action("challenge", "拔剑求战", ...)` — 直接挑战

选择「承认不敌」：
- 独孤剑意：「很好。知耻近乎勇。你已悟得剑道第一义。」— 给予 buff「剑道顿悟」：此战中对独孤剑意的伤害 +25%
- 哲学含义：无剑境界的第一层奥义——"谦逊"，承认自己的渺小才能触及伟大

选择「拔剑求战」：
- 独孤剑意：「无谓的勇气，看来你还没明白。」— 不给 buff，正常开战

**战斗：独孤剑意残影**

这是最终 BOSS，分 2 个阶段：

**第一阶段 — 有招之境**：
- 独孤剑意会使用玩家**已装备技能库中随机 3 个技能**（他在复制你的武功）
- 每次使用一个技能后，会冷却 10 秒，然后随机换另一个
- 玩家需要应对自己的招式

**第二阶段 — 无招之境**（HP < 40% 触发）：
- 独孤剑意不再使用任何技能，改为**纯粹普通攻击**
- 但每次普通攻击的伤害 = 玩家当前 HP 的 8~15% + 固定值
- 同时免疫所有控制效果和破防
- 这是"无招胜有招"的具象化——最简单的攻击，最难防御
- `on_heart_beat` 每 30 秒释放一次「天地皆剑」：全屏伤害，`me.damage2(me.max_hp * 0.2)`

击败后：
- 独孤求败残影消散，留下最后一句话：「多谢。一千年了，我终于……败了。」
- 全服广播
- 获得「剑道印记」——用于兑换奖励

**新鲜在哪**：
- 哲学选择（承认不敌 vs 拔剑求战）
- BOSS 会复制玩家的技能
- 第二阶段放弃一切招式，回归最纯粹的剑
- 整个战斗是对"无招胜有招"的诠释

**使用机制**：`add_action`（哲学选择）、`set_npc`、`on_heart_beat`（阶段切换 + 全屏 AOE）、`on_attack_over`（技能复制）、`damage2`、`add_status`

## 六、奖励设计

### 核心问题：不让其他门派学到门派专属技能

**解决方案**：不产出任何门派专属技能书。奖励全部走**通用材料 + 专属装备 + 剑道兑换**路线。

### 击败独孤剑意残影掉落

|--------|------|
| `obj/sp/jz/jiandao_yin` | **剑道印记** ×1~3（必掉），用于兑换 |
| `obj/eq/lv5/wushen/jianyi_jade` | 剑意玉佩（新 lv5 饰品，通用，加剑法伤害 + 暴击） |
| `money/xuanjing` | 玄晶 ×10~50（通用精炼材料） |
| `money/yuanjing` | 元晶 ×5~20（通用锻造/洗练材料） |
| `eq/lv3/huangbaoshi` ~ `eq/lv3/zuanshi` | 随机高级宝石 ×3~8（通用镶嵌材料） |

| 兑换物 | 消耗 | 说明 |
|--------|------|------|
| 元晶 ×50 | 1 印 | 洗练装备 |
| 高级宝石礼包（随机 lv3 宝石 ×10） | 2 印 | 镶嵌 |
| 独孤九剑残页 ×30 | 3 印 | 可合成独孤九剑书（通用书籍学习，不限门派） |

| 剑魔称号「独孤求败」 | 30 印 | 永久称号，全属性 +5%，附加特效 |

> 所有奖励都是**通用**的，不涉及任何门派专属技能。

## 七、新鲜之处总结

与现有副本/禁地的对比：

| 对比维度 | 现有副本（以慈航静斋为例） | 独孤剑冢 |
|---------|--------------------------|---------|
| 谜题类型 | Q&A、方向迷宫 | 观察找路、序列踩踏、献祭抉择、卸武空手 |
| 战斗节奏 | 走到 BOSS → 站桩输出 | 每个房间改变战斗规则，玩家被迫适应 |
| BOSS 机制 | 多阶段、心魔复制属性 | 复制技能、预警闪避、无招普攻 |

## 九、使用 vs 不使用的机制

| 使用的机制 | 用在哪 |
|-----------|--------|
| `add_action`（自定义按钮） | 每个房间 2~9 个 |
| `set_npc` + `on_die` | 五个剑灵 + BOSS |
| `set_item`（隐藏物品） | 入口石碑、各房间的剑 |
| `add_status`（状态效果） | 剑冢试炼压制、木剑反噬、剑道顿悟 |
| `damage2`（真伤） | 陷阱、献祭、反噬、BOSS 大招 |
| `set_temp` / `query_temp` | 境界进度、献祭量、序列追踪 |
| `on_enter` | 木剑境检测武器 |
| `on_heart_beat` | 预警、形态切换、全屏 AOE |
| `on_attack_over` | 复制技能、改变攻击形态 |
| `send_question` | 不用（刻意避免，改用更新颖的交互） |

| 不使用的机制 | 原因 |
|-------------|------|
| 心魔镜像（`NPC.CREATE` 复制玩家） | 已在净念禅宗和慈航静斋大量使用 |
| `send_question` 问答题 | 已有多个副本使用，改为观察/序列/献祭等新形式 |
| 扫荡（`quick_drops` / `on_quick_over`） | 禁地定位，不支持扫荡 |
| 多队伍模式 | 禁地单人 |
| 困难模式 | 禁地只有一种难度 |
