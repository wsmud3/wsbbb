## 三、属性分类与对照表

### 3.1 基础战斗属性 (category 0) — 固定数值，精炼成长

| Key | 中文名 | 装备中使用 | 技能中使用 | 在 recount() 中的作用 |
|-----|--------|-----------|-----------|----------------------|
| `gj` | 攻击 | ✓ 武器/暗器主属性 | ✓ 技能启用心法、自创词条 | 基础伤害：`str + (gj + str*str/10)*(1+gj_per/100)` |
| `fy` | 防御 | ✓ 防具主属性 | ✓ 技能启用心法 | 伤害减免：`((str+con)/10 + fy + con*con/10)*(1+fy_per/100)` |
| `mz` | 命中 | ✓ 戒指主属性 | ✓ 技能启用心法 | 命中判定：`(dex/2 + mz)*(1+mz_per/100)` |
| `ds` | 躲闪 | ✓ 项链主属性 | ✓ 技能启用心法 | 闪避判定：`(dex/2 + ds + dex*dex/5)*(1+ds_per/100)` |
| `zj` | 招架 | ✓ 护腕主属性 | ✓ 技能启用心法 | 格挡判定：`(str/2 + zj + str*str/5)*(1+zj_per/100)` |
| `max_hp` | 气血上限 | ✓ 常见防具属性 | ✓ 内功 `query_prop` | 直接增加气血上限 |
| `max_mp` | 内力上限 | 较少使用 | ✓ 内功 | 直接增加内力上限 |
| `limit_mp` | 内力上限 | ✓ 腰带等 | ✓ 内功 `force` | 内力上限(别名) |

### 3.2 后天属性 (category 1) — 固定数值，精炼成长

| Key | 中文名 | 装备中使用 | 技能中使用 | 战斗公式影响 |
|-----|--------|-----------|-----------|-------------|
| `str` | 臂力 | ✓ 武器/护腕 | ✓ 技能启用心法、自创词条 | 影响 `gj`(攻击) 和 `zj`(招架) |
| `con` | 根骨 | ✓ 衣服/腰带 | ✓ 技能启用心法 | 影响 `fy`(防御) |
| `dex` | 身法 | ✓ 鞋/披风 | ✓ 技能启用心法、轻功 | 影响 `mz`(命中) 和 `ds`(躲闪) |
| `int` | 悟性 | ✓ 武器/饰品 | ✓ 技能启用心法 | 影响技能学习等 |

> **后天属性参与 `recount()` 的核心战斗公式**：
> - `gj = str + (gj总和 + str后天*str先天/10) * (1 + gj_per%/100)`
> - `ds = dex/2 + ds总和 + dex后天*dex先天/5 + (专注加成) * (1 + ds_per%/100)`

## 五、核心战斗公式 (recount)

```js
// 攻速
gjsd = 4000 - prop("gjsd")
gjsd = gjsd - gjsd * prop("gjsd_per") / 100   // 最低 500ms

// 攻击
gj = str + (prop("gj") + prop("str")*str/10) * (100 + prop("gj_per")) / 100

// 防御
fy = ((str+con)/10 + prop("fy") + prop("con")*con/10) * (100 + prop("fy_per")) / 100

// 命中
mz = (dex/2 + prop("mz")) * (100 + prop("mz_per")) / 100

// 躲闪
ds = (dex/2 + prop("ds") + prop("dex")*dex/5) * (100 + prop("ds_per")) / 100
// 专注(zc_focus)加成：dex*dex/5 部分 * (1 + zc_focus)

// 招架
zj = (str/2 + prop("zj") + prop("str")*str/5) * (100 + prop("zj_per")) / 100

// 暴击
bj = dex/10 + prop("bj_per")
```

> 代码位置：[world/extends/char/combat.js:2-38](../world/extends/char/combat.js#L2-L38)

## 六、装备精炼成长规则

在 [os/item/equipment.js:309-377](../os/item/equipment.js#L309-L377) 的 `levelchange_prop()` 中：

| 属性类别 | 精炼成长方式 | 倍率 |
|----------|-------------|------|
| **基础/后天**（gj/fy/mz/ds/zj/max_hp/max_mp/str/con/dex/int等） | `value + value * val / 100` | 随 levelData 增长 |
| **生命/采集类**（diff_busy/busy_per/caiyao1/diaoyu1/kuang1/lianyao1/expend_mp/busy） | `value + value * val / 1000` | 1/10 于基础属性 |
| **高级/稀有/特殊**（per/gjsd/gjsd_per/distime_per/releasetime_per/gj_per/fy_per等百分比类） | **自制装备**：不成长<br>**红装**：`value + value * val / 1000` | 红装微幅成长 |
| **先天**（str1/con1/dex1/int1/kar） | 不成长 | 固定值 |
| **技能**（skill） | 不成长 | 固定值 |

> 精炼等级系数 `levelData`：`[0, 4, 7, 15, 26, 41, 60, 82, 108, 138, 172, 209, 250]`
