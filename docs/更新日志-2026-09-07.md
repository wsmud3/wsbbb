## Astra 方案：稳定性、安全性与发布流程

- **管理员会话**：后台权限改为服务端会话与数据库实时校验；补充严格的会话过期、管理员等级和 IPC 密钥校验，普通账号及过期凭证不能访问管理接口。
- **账号恢复**：默认关闭不安全的公开找回密码接口；只有显式启用并接入恢复令牌提供方后才允许恢复流程。
- **请求边界**：公开 API 按方法白名单限制 GET/POST，内部方法不再可由路径直接调用；`/reload` 改为受限 POST；健康检查默认只返回状态，详细信息需健康令牌。
- **启动与持久化**：Web 服务等待配置和数据库初始化完成后再监听；批量保存逐角色报告失败并保留可恢复快照；关服等待保存结果，失败以错误状态退出。
- **山外山奖励**：里程碑奖励采用待领取记录、原子领取标记和串行提交，崩溃或入包失败可恢复，重复领取不会重复发放。
- **通信与战斗**：补强 WebSocket 分片、UTF-8、关闭状态和原始 TCP 边界；修复自创属性重算、反震递归和真意一次性触发状态。
- **发布与回归**：部署前端构建失败会阻断发布；新增 GitHub Actions，在 Node 22 下执行完整测试和 Vite 生产构建。
