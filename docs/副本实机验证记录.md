## 本次验证发现并修复的问题

1. **动作名带空格导致命令失效**（全仓 9 处）
   `"tan qin"` 被命令分发器按空格切分 → 只认 `tan` → 一律回「什么？」。
   改为无空格连写（`tanqin` / `kanhua` / `pashu` / `guoqiao` / `shangzhonglou` /
   `yidong` / `chakan`），按钮显示名不变。

2. **温家五老被生成两遍**
   采集数据里五老是静态分布在府中各处（大厅温方达、亭子温方义+温方山、
   侧房温方施/温方南，尸体位置可证），木桩又生成一遍 → 场上 10 个、分数翻倍。
   木桩改为「五老未清 → 提示阵法不成；全清 → 召唤金蛇郎君」。

3. **净念禅宗 殿门 north 指回山门（自环）**
   山门→石阶→殿门 之后又退回山门，前院/大雄宝殿/观音殿/后山崖/崖底 全不可达，
   盗帅线无法开始。改为 殿门 north → 前院。可达房间 5/22 → 18/22。

4. **衡山 衡阳西街指向不存在的 liufudamen**
   整条刘府链断掉，费斌（通关目标）打不到。改为 liufumen 并补 north。

5. **白驼山 西门未通草丛**
   草丛/北草丛/岩洞 三间孤立，蟒蛇打不到。改为西门 west → caocong。

6. **黑木崖 树林 east 指向空悬崖 up1、密道进得去出不来**

## 约定（避免再犯）

- 动作名/物品动作名**不能含空格**
- 物品动作的实际命令是 `<动作名> <物品id>`，NPC 动作是 `<动作名> <npc实例id>`
- 改完必须立刻 commit + push，否则部署脚本会因 `Dirty checkout` 拒绝部署
