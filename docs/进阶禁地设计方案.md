# 进阶禁地设计方案

## 零、总览

### 何为进阶禁地

进阶禁地是各门派玩家在达到**武帝境界 + 武道塔100层**后解锁的门派专属高难挑战。与通用禁地（黑鹰校场、绿柳山庄）不同，进阶禁地：

- **门派绑定**：只有对应门派的玩家可以进入
- **境界门槛**：武帝（level ≥ 4）+ 武道塔 ≥ 100 层
- **奖励定位**：产出通用高端材料 + 门派专属毕业装备/称号，不产出其他门派技能
- **设计哲学**：每个禁地围绕该门派的武学哲学设计，解密与战斗深度融合

### 进入判定（以华山为例）

```javascript
// 在禁地区域 on_enter 中
if (me.family !== FAMILIES.HUASHAN)
    return me.notify("只有华山派弟子才能踏入剑冢。");
if (me.level < 4)
    return me.notify("你境界未到武帝，无法承受剑冢中的剑意。");
if (me.query_temp("wd_level", 0) < 100)
    return me.notify("你尚未通过武道塔第一百层，剑冢之门不会为你开启。");
```

## 一、华山派进阶禁地：独孤剑冢

### 1.1 背景

> 剑魔独孤求败，纵横江湖三十余载，杀尽仇寇，败尽英雄，欲求一败而不可得。晚年隐于华山深谷，将其一生剑道感悟与四柄佩剑埋于一处，是为**剑冢**。
>
> 他在冢前留字：「剑分五境——利剑无意，软剑无常，重剑无锋，木剑无俦，无剑无招。」五境之中，藏有剑魔毕生剑意。
>
> 华山派历代高手均知剑冢存在，却无人能走到最后。风清扬曾言，他当年走到第三境重剑便已力竭。唯有踏入武帝之境、身经武道塔百层历练的华山弟子，方有资格一试。
>
> 江湖传言：**「破五境者，得见无剑。」**

#### [0] 华山绝壁 `jz/juebi`

**描述**：
> 华山后山一处人迹罕至的绝壁。云雾终年不散，崖壁上隐约可见一道被山崩撕开的裂缝，内里透出幽幽青光。裂缝旁的石壁上刻着两行大字：
>
> 「纵横江湖三十余载，杀尽仇寇，败尽英雄，欲求一败而不可得。」
>
> 落款处是一道深达三寸的指痕——**剑魔独孤求败**。

**机制**：
- `set_item("jz_shibi", "独孤留字石壁", "...", ["参悟留字"])` — 获得剑冢 lore + 五剑境界的基本提示
- `add_action("enter_jz", "踏入剑冢裂缝", ...)` — 触发进入判定（门派/境界/武道塔），通过后进入剑冢外道
- 进入时施加「剑冢试炼」debuff：全属性 -15%（全局压制，随五境突破逐步解除，每破一境 +3%）

**类型**：纯交互，无战斗

#### [1] 剑冢外道 `jz/waidao`

**描述**：
> 一条仅容一人通过的狭长山缝，两侧岩壁湿滑冰冷。黑暗中每隔数十步才有一枚嵌在壁上的萤石发出微光。脚下碎石间，偶尔能看见锈蚀的断剑残片，不知是何年何月被遗弃在此。空气中弥漫着一股若有若无的剑意，令人脊背发凉。

**机制**：
- `set_npc("jz/jianyi_yeling", 3)` — 3 只「剑意野灵」，剑冢外围剑意自行凝聚成的灵体，实力弱但数量多，起到热身作用
- 野灵击败后概率掉落「剑意碎片」（小概率），集齐 20 个可合成「剑意护符」（临时 buff 道具）
- 击败全部野灵 → 剑意暂时消散，通道尽头亮起微光，进入剑器长廊

**类型**：战斗（小型热身）

#### [2] 剑器长廊 `jz/jianqichanglang`

**描述**：
> 一条由青石砌成的长廊，两侧各有两座石质剑架，一字排开共四座。每座剑架上陈列着一柄剑的青铜复制品，下方刻着独孤求败亲笔所书的铭文：
>
> - 第一座：**利剑** 「凌厉刚猛，无坚不摧。弱冠前以之与河朔群雄争锋。」
> - 第二座：**软剑** 「紫薇软剑，三十岁前所用。误伤义士不祥，乃弃之深谷。」
> - 第三座：**重剑** 「玄铁重剑，重剑无锋，大巧不工。四十岁前恃之横行天下。」
> - 第四座：**木剑** 「四十岁后，不滞于物，草木竹石，均可为剑。」
>
> 长廊尽头第五座剑架上空空如也，下方铭文只有简短的四个字——**「自此无剑」**。

**机制**：
- 纯粹的 lore/氛围房间，无战斗
- `add_action("examine_lijian", "观摩利剑", ...)` — 查看利剑细节，获得利剑境的提示
- `add_action("examine_ruanjian", "观摩软剑", ...)` — 查看软剑细节，获得软剑境的提示
- `add_action("examine_zhongjian", "观摩重剑", ...)` — 获取重剑属性，理解「大巧不工」
- `add_action("examine_mujian", "观摩木剑", ...)` — 获取木剑属性
- `add_action("examine_wujian", "凝视空剑架", ...)` — 独孤求败的留音回荡：「剑已在心中，何须陈列？」

**类型**：纯交互/lore

#### [3] 利剑阁 `jz/lijiange`

**描述**：
> 第一座剑冢。一柄青光闪闪的利剑斜插于石台之上，剑身薄如蝉翼，刃口隐现寒芒。四壁满是深浅不一的剑痕，仔细看去，每面墙上的剑痕似乎排列成不同的走向——有的指向高处，有的斜向地面，有的呈弧形游走。利剑的锋锐之气充盈整个石室，令人汗毛倒竖。

**谜题：观察找路**

房间有 4 个出口（对应东/南/西/北），但只有一个是正确通道：
- 需要分别检查四面石壁：`add_action("check_east", "检查东壁剑痕", ...)` 等
- 四面石壁各有不同描述，正确的一面描述中有"剑痕的末端隐有微光透出"
- 每次进入时正确方向随机（`Math.random` 在 `on_create` 中决定）
- 选错 → 剑意反噬 `me.damage2(me.max_hp * 0.15)` + 房间提示「剑气逼退了你」
- 选对 → 提示「剑痕尽头，光芒大盛——利剑台的方向就在前方」

同时 `set_npc("jz/lijian_ling")` 出现，玩家需在探索出路的同时应对战斗。

**战斗：利剑剑灵**
- 高速纯物理攻击，暴击率 +20%
- 无任何花哨技能，纯粹以快打慢
- 贯彻"利剑无意"——直来直往，剑气锋锐

**类型**：观察谜题 + 战斗（并行）

#### [4] 利剑台 `jz/lijiantai`

**描述**：
> 穿过剑痕密布的通道，眼前豁然开朗。一座圆形石台悬于深渊之上，四周只有黑暗。利剑剑灵已在此等候——它不再是一柄剑，而是一个与你等高的人形剑影，手握青光长剑。
>
> 石台边缘立着一块小碑：「此境考验剑之锋锐。以快制胜，以锋破敌。」

**战斗：利剑剑灵（强化）**

不同于利剑阁中的骚扰，这里是正式对决：
- HP 为玩家的 60%
- 攻击力 = 玩家攻击力 × 0.8
- 攻击速度加倍
- 击败后 → 「利剑剑意」消散，解除第一层压制（全属性 +3%）
- 掉落利剑碎片（后续兑换材料）

**类型**：纯战斗

#### [5] 软剑阁 `jz/ruanjiange`

**描述**：
> 第二座剑冢。一柄紫薇软剑横放石台之上，剑身柔软如绸，在没有风的洞中却自行颤动不休，发出嗡嗡剑鸣。石台周围的地面上，九块青石砖排成三行三列，每块砖上分别刻着一个古篆——「总」「破」「气」「剑」「刀」「枪」「掌」「索」「箭」。软剑的每一次颤动，都会让其中一块石砖亮起微光，随即熄灭。

**谜题：独孤九剑序列**

软剑的震动提示了踩踏顺序（对应独孤九剑的九式口诀）：
1. 观察软剑震动 → 石砖亮起的顺序，每次不同
2. 按照亮起的顺序用 `add_action("step_N", "踩踏第N块石砖", ...)` 依次踩踏
3. 共 5 步（不是 9 步，降低复杂度），踩错 → 软剑嗡鸣大作，`me.damage2(me.max_hp * 0.1)`，序列重置
4. 踩对全部 → 软剑停止震动，软剑剑灵从剑身中脱出

**亮点**：不同于七重门的固定路径，这里的序列是**动态的**——每次进入房间时顺序随机（在 `on_create` 中 `Math.random` 决定），玩家必须观察描述而非背板。

**类型**：序列观察谜题

#### [6] 软剑台 `jz/ruanjiantai`

**描述**：
> 软剑台比利剑台更大，地面铺着柔软的青苔。软剑剑灵的身形飘忽不定，时而如蛇蜿蜒，时而如鞭横扫。空气中到处都是它变幻莫测的残影。

**战斗：软剑剑灵**
- 每 10 秒切换一种攻击形态（刺/劈/撩/扫/缠）
- 不同形态下免疫特定类型的攻击：刺形态免疫直刺技能、扫形态免疫横扫技能等（需玩家切换技能应对）
- 闪避率 +30%（软剑无常，难以捉摸）
- 击败后解除第二层压制

**类型**：纯战斗（形态切换）

#### [7] 剑渊 `jz/jianyuan`

**描述**：
> 一条不知深浅的裂缝横亘在地面，从上往下看只有无尽黑暗。独孤求败当年在此掷下了误伤义士的紫薇软剑——剑虽已弃，剑意却千年未散。深渊中隐约能看见一点紫光，明灭不定。若有勇气，或可垂索而下。

**机制**：
- 这是一条**可选分支**，不下剑渊也可继续前进（有另一条路通往重剑殿）
- `add_action("descend", "垂索而下", ...)` — 下降到剑渊底部（需要身法 ≥ 1500 或 轻功等级达标，否则摔下去掉血）
- 渊底有 `set_item("jz_ziweiruanjian", "紫薇软剑残片", "软剑虽已锈蚀，残片中仍蕴含一缕剑意。", ["拾取"])`
- 拾取后获得「紫薇剑意」buff：最终战中对独孤剑意的暴击率 +15%
- 渊底也有一个**隐藏小 BOSS**「剑渊怨灵」（软剑误伤义士后残留的怨念），击败后额外获得「剑意碎片」×10
- 攀回地面需要 `add_action("climb_up", "攀回地面", ...)`

**类型**：可选分支探索 + 隐藏战斗

#### [8] 重剑殿 `jz/zhongjiandian`

**描述**：
> 第三座剑冢。一柄通体漆黑的玄铁重剑直直插入巨石之中，剑身粗厚无刃，与其说是剑，不如说是一块巨大的铁尺。重剑散发出沉重的压迫感，空气都为之凝滞。重剑之后，一道巨大的石门封住去路，门上只有一个血红色的掌印凹槽——**需以鲜血为引，方能开启**。

**谜题：献祭抉择**

- `add_action("sacrifice_30", "献祭三成气血", ...)` → 献祭 30% 当前 HP，石门打开，但重剑剑灵强度 = 100%
- `add_action("sacrifice_50", "献祭五成气血", ...)` → 献祭 50% 当前 HP，石门大开，重剑剑灵对你产生敬意，强度 = 80%
- `add_action("sacrifice_70", "献祭七成气血", ...)` → 献祭 70% 当前 HP，石门轰然洞开，重剑剑灵认可你的决心，强度 = 60%，且战斗开始前送你一枚「玄铁碎片」
- 献祭不足 30% → 石门纹丝不动

这是一个**风险/收益权衡**：血越少越危险，但 BOSS 越弱。

**战斗：重剑剑灵**
- 攻击间隔是正常的 2 倍（极慢）
- 每次攻击伤害是正常的 2.5~3 倍（毁灭性）
- 攻击前 3 秒房间描述变化：地面震动、石屑簌簌落下 → 预警
- 玩家可在预警期间使用 `add_action("dodge_heavy", "侧身闪避", ...)` 尝试闪避（成功率 = 轻功/(轻功+BOSS命中)）
- 击败后解除第三层压制
- 掉落「玄铁碎片」×1（如果之前没获得的话）+ 剑意碎片

**类型**：献祭谜题 + 预警闪避战斗

#### [9] 洗剑池 `jz/xijianchi`

**描述**：
> 穿过重剑殿，竟是一片小小的地下湖泊。湖水清澈见底，湖底铺着一层亮晶晶的矿物质，散发出柔和的暖意。这应该是山腹中的天然温泉，大概是独孤求败当年洗剑休憩之处。湖边散落着一些生活痕迹——一个石枕、一方石桌、几卷早已化为齑粉的帛书残迹。

**机制**：
- 过渡/休息房间，无战斗
- `add_action("rest_in_spring", "入温泉调息", ...)` — 恢复全部 HP/MP，但只能使用一次
- `add_action("examine_table", "查看石桌遗迹", ...)` — 石桌上刻着独孤求败的随笔：「今日斩燕十三剑，剑剑不同。问世间，谁能懂此寂寞？」
- 氛围铺垫：从这一间开始，剑冢的画风从"试炼"转向"孤独"——无剑境界即将到来

**类型**：恢复点 + lore

#### [10] 木剑阁 `jz/mujiange`

**描述**：
> 第四座剑冢。出乎意料地简陋——石台上只放着一柄朽木削成的木剑，剑身满是裂纹，似乎一碰即碎。然而当你靠近时，你腰间的兵刃竟自行颤抖起来——不是恐惧，而是共鸣。
>
> 木剑前方，一道透明的人影盘膝而坐。他没有起身，只是淡淡说道：「放下你的剑。在这里，它只会成为你的束缚。」
>
> 话音刚落，你若没有卸下武器，手中的兵刃便开始发出尖锐的哀鸣——每过片刻便有一股剑意反噬而来。

**谜题：放下武器**

- 若玩家装备了武器 → 每 5 秒触发一次剑意反噬 `me.damage2(me.max_hp * 0.03)`
- `add_action("lay_down_weapon", "卸下武器", ...)` — 将武器卸入背包
- 卸下后，反噬停止，木剑剑灵现身，缓缓说道：「很好。现在——让我看看你的真本事。」
- 玩家只能使用拳脚/掌法/内功进行后续战斗

**战斗：木剑剑灵**

### 1.5 新系统：剑意（触发式被动）

#### 设计定位

**不是数值加成，是触发式机制。** 每种剑意有一个触发条件和一个 CD 限制的效果。玩家可以根据战斗场景切换剑意——打 BOSS 用重剑硬刚、打多个小怪用利剑连击、绝境切无剑保命。同一个角色、同一套装备，不同剑意打出不同风格。

跟称号的区别：称号纯展示。跟装备的区别：剑意跟角色不跟装备，换装备不影响。

#### 华山剑意列表

设计原则：**触发条件必须是华山玩家自然会做的操作**（出剑、连击、运紫霞、耗内力），不能是华山不堆的属性（闪避、格挡）。

完成剑冢不同阶段解锁不同剑意，可在传承殿随时切换：

| 剑意 | 解锁 | 触发条件 | 效果 | CD | 机制类型 | 设计逻辑 |
|------|------|---------|------|-----|---------|---------|
| **利剑** | 击败利剑剑灵 | 5s内对同一目标命中 3 次 | 打断目标当前动作，**沉默** 3s（无法使用技能） | 20s | 打断/沉默 | 「凌厉刚猛」— 快到对方来不及出招，以攻为禁 |
| **软剑** | 击败软剑剑灵 | 剑法技能后 4s 内普攻命中 | 软剑**缠兵**：目标普攻伤害 -40% 且每次普攻反弹(攻击×0.2)真伤，持续 5s | 15s | 缴械/反伤 | 「变化无常」— 以柔克刚缠锁兵刃，敌愈攻则自伤愈重 |
| **重剑** | 击败重剑剑灵 | 单次技能消耗内力 > 自身最大内力 15% | 目标获得「**内伤**」：每次使用技能受到自身最大 HP 3% 真伤，持续 8s | 25s | 内伤反制 | 「大巧不工」— 重剑无锋但力透脏腑，不砍血肉震内脏 |
| **木剑** | 击败木剑剑灵 | 使用内功技能后 8s 内 | 下次剑法消耗的内力值 **100% 转化为护盾**，持续 10s | 20s | 资源转化 | 「不滞于物」— 内气外放，内力即剑亦为甲 |
| **无剑** | 击败独孤剑意残影 | HP 首次 < 20% | 清除所有负面状态，10s 内**免疫控制 + 每次受击自动反击**(普攻 50% 伤害) | 每战 1 次 | 领域/反击 | 「无剑无招」— 万物皆剑，敌攻我即是攻入剑阵 |

#### 战斗风格对照

每种剑意对应一种不同的**战斗决策**，而非不同数值：

- **利剑 = 打断控制**：追连击沉默对手，克制依赖技能的门派/敌人，适合先手压制
- **软剑 = 缴械弱化**：削弱目标普攻并反弹伤害，克制平A流，适合消耗战
- **重剑 = 内伤反制**：给目标上"出招即自损"debuff，克制高频技能流，适合打 BOSS
- **木剑 = 护盾转化**：内功→剑法的 MP 消耗变成护盾，攻防一体，适合持久战
- **无剑 = 领域反击**：绝境中免控+挨打自动反击，克制多段攻击，翻盘底牌

#### 设计原则总结

1. **触发可自主选择**：每个触发的条件都不相同，但都是玩家在对应风格下自然会做的操作，且触发难度相近——不存在"永远触发不了"或"被动就触发"
2. **效果是机制而非数值**：沉默/缴械/内伤/护盾转化/领域反击——五种机制对应五种克制关系，有策略深度
3. **克制链条**：利剑(沉默)克技能流 → 技能流被克后只能用普攻 → 软剑(缴械)克普攻流 → 重剑(内伤)克高频出招 → 木剑(护盾)拖持久战 → 无剑(反击)克多段攻击

旧设计的核心问题：
```
旧·全部真意 = "条件→+X%伤害" 或 "条件→+X%减伤"
→ 玩家体感：只是换了个姿势喝药水，没有玩法变化
→ 平衡问题：增伤高的太强，增伤低的太弱，触发难的不如触发简单的

新·华山五剑意 = 五种不同机制（沉默/缴械/内伤/护盾/反击）
→ 玩家体感：不同战斗选不同剑意，打法和克制关系完全不同
→ 平衡：每种机制有克制和被克制，不存在绝对最优

#### 技术实现

利用游戏已有的 `on_attack_over`、`on_damage` 等战斗钩子，不需要新架构：

    // 例：利剑剑意
    if (intent_id === "lijian") {
        this._lijian_hits = 0;
        this._lijian_last_hit = 0;
        // 在 on_attack_over 中：
        //   检查时间窗口 + 命中计数 → 触发 → 进入 CD
    }

```

**设计统一性**：
1. **通用材料 + 精炼符 + 纯展示称号**：所有门派一致，走现有系统
2. **武道真意**：各门派都是「五种真意 = 五种不同机制」，不再是数值加减，而是沉默/缴械/恐惧/隐身/内伤/护盾转化/延迟伤害/领域反击等机制变量
3. **每个门派有克制链**：不同真意克制不同战斗风格，玩家根据对手切换，形成策略深度
4. 弱势门派（如少林）真意触发条件更宽松，且携带更多控制/生存机制（恐惧、沉默、免控、金钟罩），作为隐性平衡
