1. **温府**：进门翻墙→大厅温方达→走廊→亭子跳木桩(1v5)→清完再跳→小院(金蛇)→北→小楼(温仪)→杀金蛇→`cr` 应 100%
2. **关外**：东线杀金雕×3/东北虎×3/黑熊→回大门→`cr` 应 80%→付船夫 1 两→江面→船厂→雪地→西行5次→荒地→北→山神庙杀阎基→`cr` 应 100%
3. **血刀门**：山口→山谷→忘忧谷→(东上)洞口→(enter)山洞，看血刀老祖是否在场
4. **白驼山**：大门→练功场→长廊→西门→草丛→草丛→竹林→石洞
5. **缥缈峰**：山脚→断魂崖(铁索桥)→仙愁门→…→闭关室
